# 逻辑函数化简笔记整理

## 一、公式法化简

### 常用公式

1. **吸收律1**：$\boldsymbol{A + AB = A}$
2. **合并律**：$\boldsymbol{AB + AB' = A}$
3. **冗余律**：$\boldsymbol{AB + A'C + BC = AB + A'C}$
4. **吸收律2**：$\boldsymbol{A + A'B = A + B}$

## 二、卡诺图化简法

### 三变量卡诺图（以$ABC$为例）

- 列序要求：按$\boldsymbol{00、01、11、10}$排列，保证相邻格只变一个变量，且最上/最下、最左/最右同样有相邻属性
- 格子对应最小项示例：
  - $A$行：$AB'C'、AB'C、ABC、ABC'$
  - $A'$行：$A'B'C'、A'B'C、A'BC、A'BC'$

### 四变量卡诺图

- 行/列序：均按$\boldsymbol{00、01、11、10}$排列
- 相邻性：上下、左右、首尾（行首尾、列首尾）均相邻

### 化简核心规则

**相邻消去法**：将相邻的$1$格按$2^n$（$n=0,1,2\cdots$）的数量圈组，消去圈中**变化的变量**，保留**不变的变量**，最终将所有圈对应的与项相加（本质是利用$AB + AB' = A$，把相邻项凑成全集$1$从而消去变化变量）
