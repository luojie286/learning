# 01 · 逻辑函数化简

> 一句话概括：公式法靠**定律硬推**，卡诺图靠**图形化圈组**——两者本质都是利用 $\boldsymbol{AB + AB' = A}$ 把相邻项凑掉一个变量。

---

## 一、公式法化简

### 四个核心公式

1. **吸收律 1**：$\boldsymbol{A + AB = A}$
2. **合并律**：$\boldsymbol{AB + AB' = A}$
3. **冗余律**：$\boldsymbol{AB + A'C + BC = AB + A'C}$
4. **吸收律 2**：$\boldsymbol{A + A'B = A + B}$

### 怎么用

化简就是反复「**找能套公式的形状**」：

```text
看到 A + AB      → 用吸收律 1，直接去掉 AB
看到 AB + AB'     → 用合并律，合并成 A
看到 AB + A'C + BC → 用冗余律，去掉 BC 这一项
看到 A + A'B      → 用吸收律 2，变成 A + B
```

> 公式法的局限：**没有固定套路**，能不能化简成功很看经验和眼力，项数一多就容易卡住。这也是卡诺图存在的理由。

---

## 二、卡诺图化简法

卡诺图把真值表重新排布，使**逻辑相邻的最小项在图上物理相邻**，从而一眼就能看出哪些项可以合并。

### 2.1 三变量卡诺图（以 $ABC$ 为例）

列的排列顺序必须是 $\boldsymbol{00、01、11、10}$（格雷码），**不能用 00、01、10、11**——只有这样才能保证相邻格之间**只变一个变量**。

| | $B'C'$ (00) | $B'C$ (01) | $BC$ (11) | $BC'$ (10) |
|---|---|---|---|---|
| $A$ | $AB'C'$ | $AB'C$ | $ABC$ | $ABC'$ |
| $A'$ | $A'B'C'$ | $A'B'C$ | $A'BC$ | $A'BC'$ |

### 2.2 四变量卡诺图

行、列**都按 $00、01、11、10$ 排列**（16 格）。

相邻关系（这是卡诺图的精髓）：

```text
上下相邻、左右相邻     → 相邻 ✅
行首尾相邻、列首尾相邻 → 也相邻 ✅（因为格雷码首尾也只差一位）
```

也就是说：**最左列与最右列相邻，最上行与最下行相邻**——卡诺图是「卷起来」的。

### 2.3 化简核心规则：相邻消去法

**操作步骤**：

```text
1. 把真值表填入卡诺图（为 1 的格子标 1）
2. 把相邻的 1 格按 2ⁿ 个（1、2、4、8、16……）圈成一组
3. 每一组消去「组内变化的变量」，保留「组内不变的变量」
4. 把每个圈对应的与项相加（或项之积再求和）
```

**圈组的三条原则**：

| 原则 | 说明 |
|---|---|
| 数量必须是 $2^n$ | 只能圈 1、2、4、8、16 个，**不能圈 3 个、5 个** |
| 圈要尽量大 | 圈越大，消掉的变量越多，结果越简 |
| 圈可以重叠 | 同一个 1 可以被多个圈共用（但每个圈至少要有一个「独占」的 1，否则是多余圈） |

**为什么消去的是「变化的变量」**：

本质就是 $\boldsymbol{AB + AB' = A}$——两个格子在某个变量上取值相反，其余变量相同，那么这一个变量就被消掉了。

```text
ABC + ABC'  →  变量 C 变化，保留 AB  →  化简为 AB
```

## 三、两种方法的比较

| | 公式法 | 卡诺图 |
|---|---|---|
| 依据 | 布尔代数定律 | 图形化圈组 |
| 优点 | 变量数多时理论可行 | **直观、不易出错、结果通常最简** |
| 缺点 | 无固定套路，依赖经验 | **仅适合变量数较少（一般 ≤ 5~6 个）** |
| 适用 | 快速局部化简 | 完整化简、考试首选 |

> 变量超过 5~6 个时卡诺图就不实用了，工程上改用 **Q-M 表格法**或直接交给工具——现阶段掌握到 4 变量足够。

---

## 📌 易错点

1. **卡诺图列序写成 $00、01、10、11$**——这是最致命的错误，必须用格雷码 $00、01、11、10$。
2. **忘了首尾相邻**——最左列与最右列、最上行与最下行是相邻的，漏掉就化简不彻底。
3. **圈了 3 个或 5 个**——数量必须是 $2^n$。
4. **圈里没有「独占的 1」**——这个圈是多余的（所有 1 都被别的圈覆盖了），会多出一个冗余项。
5. **混淆「消去变化变量」和「保留变化变量」**——**消变化、留不变**，记反就全错。
6. **把公式法结果当成唯一解**——同一逻辑函数的最简式可能不唯一（不同圈法得到不同但等价的表达式）。

## 🧠 速记口诀

```text
四个公式：A+AB=A、AB+AB'=A、AB+A'C+BC=AB+A'C、A+A'B=A+B
卡诺图列序：00 01 11 10（格雷码），只为相邻只变一位
首尾相邻：最左最右相邻、最上最下相邻，卡诺图是「卷起来的」
圈组：只圈 2ⁿ 个、圈得越大越好、可以重叠但需有独占格
化简：消去变化变量，保留不变变量，各圈相加
```
