# 08 · 单调栈与单调队列

> 一句话概括：用「栈/队列内保持单调」把「找最近更大/更小」「滑动窗口最值」做到 O(n)——每个元素最多进一次、出一次。

## 一、单调栈：找「两侧最近的更小元素」

**一句话理解**：栈里下标对应的值保持单调递增；**一个元素被弹出栈的那一刻，触发它的人和栈里它下面的人，就是它两侧的答案**。

原模板解决的问题：对每个位置 `i`，求左边第一个**严格更小**和右边第一个**严格更小**的元素下标（都不存在则 -1）。

**难点——相等元素**：相等不算「更小」。栈内连续相等的元素**答案必然相同**（它们的左右严格更小位置一样），所以原代码用 `nextSame[]` 链表把相等元素串成一组：入栈时遇到栈顶相等，新元素**顶替**栈顶位置并把旧元素链到自己后面；弹栈时沿链把整组一起结算。

```cpp
for (int i = 0; i < n; i++) {
    // 当前值更小：栈顶元素的「右侧答案」就是 i，弹出并结算
    while (top > 0 && arr[stk[top - 1]] > arr[i]) {
        int cur = stk[--top];
        while (nextSame[cur] != -1) {          // 相等元素整组一起结算
            int t = nextSame[cur];
            ans[cur][0] = (top > 0 ? stk[top - 1] : -1);  // 左：弹出后的新栈顶
            ans[cur][1] = i;                              // 右：触发者
            cur = t;
        }
        ans[cur][0] = (top > 0 ? stk[top - 1] : -1);
        ans[cur][1] = i;
    }
    // 相等元素：顶替栈顶并挂链；否则正常入栈
    if (top > 0 && arr[stk[top - 1]] == arr[i]) {
        nextSame[i] = stk[top - 1];
        stk[top - 1] = i;
    } else {
        stk[top++] = i;
    }
}
// 循环结束后清算栈内剩余：右侧无更小 → -1
```

> 栈里**存下标不存值**——弹出时才能定位答案位置，也能回查值。

## 二、单调队列：滑动窗口最值

原文件是课堂骨架（`check` 未定义、`n/nums/window_size` 未声明，**不能直接编译**），整理成可读模板：

```cpp
deque<int> q;                      // 存下标，q 内对应的值单调
for (int i = 0; i < n; i++) {
    // ① 维护单调性：把队尾「不可能再成为最值」的弹掉
    while (!q.empty() && nums[i] <= nums[q.back()])
        q.pop_back();
    q.push_back(i);
    // ② 删除过期元素：队首滑出窗口左界
    while (q.front() <= i - window_size)         // 下标 <= i-k 即已出窗
        q.pop_front();
    // ③ 队首即窗口最值
    if (i >= window_size - 1)
        // nums[q.front()]
        ;
}
```

**为什么对**：求窗口最小值时，若 `nums[i]` ≤ 队尾元素，队尾**永远不可能**比 `nums[i]` 更晚成为最小（它比 i 早过期、值又不更小）——可以安全丢弃。每个元素最多入队一次、出队一次 → O(n)。

## 三、单调栈 vs 单调队列

| 对比项 | 单调栈 | 单调队列 |
|---|---|---|
| 结构动作 | 只在**栈顶**进出 | **队尾**进、**队尾和队首**都能出 |
| 出队原因 | 被更强的新元素弹掉 | ① 被更强的新元素弹掉（尾）② 滑出窗口（头） |
| 解决问题 | 「**最近的**更大/更小」（找左/右第一个） | 「**滑动窗口内**的最值」 |
| 典型题 | 柱状图最大矩形、每日温度、下一个更大元素 | 滑动窗口最大值、DP 优化（后续） |
| 复杂度 | O(n)，均摊 | O(n)，均摊 |

**共同本质**：及时排除「已经不可能成为答案」的元素，让候选集始终保持单调。

## 📌 易错点

1. **存值不存下标** ✗——窗口判断过期、定位答案位置都需要下标。
2. **比较符号搞错**——求「严格更小」用 `>` 弹（栈内递增）；相等元素的归属（算不算答案）要按题意决定是否成组处理。
3. **单调队列忘删过期队首**——队首可能是上一个窗口的元素，答案错。
4. **弹出时机和入队时机搞反**——先维护单调性（弹尾）→ 再入队 → 再删过期头 → 最后取队首。
5. **以为每个元素进出多次** ✗——O(n) 的来源就是每个元素**最多**一进一出。

---

## 🧠 速记口诀

```text
单调栈：栈内有序，被弹之时定答案（弹出者 ← 新栈顶 | 触发者）
单调队列：尾进尾弹保单调，头出防过期，队首永远是最值
相等元素答案同，成组结算省事
都是 O(n)：一进一出，绝不吃回头草
```
