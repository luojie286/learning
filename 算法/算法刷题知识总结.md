## 1. 复杂度与数据结构选择

当输入规模约为 `n = 10^5`：

| 复杂度 | 大致操作量 | 一般判断 |
|---|---:|---|
| `O(1)` | 常数 | 很稳 |
| `O(log n)` | 约 17 | 很稳 |
| `O(n)` | 10 万 | 很稳 |
| `O(n log n)` | 约 170 万 | 通常可过 |
| `O(n√n)` | 约 3162 万 | 取决于语言、常数和时限 |
| `O(n²)` | 100 亿 | 基本不可行 |

**注意**：这些只是经验判断，还要看测试组数、总数据量、时限、Python 常数和实现方式。

### 典型的“需求 → 数据结构”

| 需求 | 优先想到 |
|---|---|
| 频繁查找某个值是否存在 | `set` / `dict` |
| 动态获取最小值、最大值 | 堆 `heapq` / `PriorityQueue` |
| 找左/右侧第一个更大或更小元素 | 单调栈 |
| 有序数组中找满足条件的两数 | 双指针 |
| 区间左右最值信息 | 前后缀数组、单调栈等 |
| 已知节点时 `O(1)` 删除、移动 | 双向链表 |
| 按键 `O(1)` 查找又要维护使用顺序 | 哈希表 + 双向链表 |
| 子树信息合成全树答案 | 树形 DFS / 后序遍历 |

## 2. 单调栈：下一个更大元素

### 核心思想

单调栈通过维护栈内元素的单调性，一次遍历就可以找到某个元素**右边第一个更大（或更小）**的元素。

以“右边第一个严格更大元素”为例：维护**栈底到栈顶单调不增**的元素下标。遇到当前值 `nums[i]` 比栈顶值大，就弹出栈顶：当前值恰好是被弹元素右边第一个更大的数。

例子：

```text
nums = [2, 1, 5, 6, 2, 3]
答案 = [5, 5, 6, -1, 3, -1]
```

### 高频模板：右边第一个更大元素

```python
def next_greater(nums):
    n = len(nums)
    ans = [-1] * n
    st = []  # 存下标

    for i, x in enumerate(nums):
        while st and nums[st[-1]] < x:
            j = st.pop()
            ans[j] = x
        st.append(i)
    return ans
```

- 时间 `O(n)`：每个元素最多入栈一次、出栈一次。
- 空间 `O(n)`。
- **存下标更通用**：便于计算距离、访问原值。
- 处理重复值时，`<` 与 `<=` 不可随意替换：前者找“严格更大”，后者可处理“大于等于”的语义；栈内保持的非严格/严格关系也随之变化。

## 3. 贪心：买卖股票的最佳时机

题目：只能买一次、卖一次，必须先买后卖，最大化 `卖出价 - 买入价`。

### 思想

遍历到第 `i` 天时，如果这一天卖出，最优买点必然是它**之前的最低价格**。因此只需要维护：

- `min_price`：之前见过的最低买入价；
- `ans`：已经找到的最大利润。

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        min_price = prices[0]
        ans = 0
        for price in prices[1:]:
            ans = max(ans, price - min_price)
            min_price = min(min_price, price)
        return ans
```

复杂度：时间 `O(n)`，额外空间 `O(1)`（切片 `prices[1:]` 本身会分配 `O(n)` 临时列表；如需严格 `O(1)` 额外空间，改用 `for i in range(1, len(prices))`）。

严格 `O(1)` 版本：

```python
def max_profit(prices):
    lowest, ans = prices[0], 0
    for i in range(1, len(prices)):
        ans = max(ans, prices[i] - lowest)
        lowest = min(lowest, prices[i])
    return ans
```

**技巧**：先计算卖出利润，再更新历史最低价，语义上确保买入日早于卖出日。它既可以理解为贪心维护最优历史买点，也可以从动态规划视角推导。

## 4. 排序与双指针：三数之和

题目：找到所有互不重复的三元组，满足 `a + b + c == 0`，三个下标互不相同。

### 从暴力到最优常用解

- 三重枚举：`O(n³)`。
- 固定一个数，用 `set` 查两数之和：`O(n²)`，但还要处理重复答案。
- **排序 + 双指针**：`O(n²)`，去重逻辑直观，是标准做法。

排序后固定 `nums[i]`，剩下两个指针 `l=i+1, r=n-1`：

- 和 `< 0`：`l += 1`（需要更大的数）。
- 和 `> 0`：`r -= 1`（需要更小的数）。
- 和 `== 0`：保存答案，跳过重复的左右值，再向内移动。

### 标准模板

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        n = len(nums)
        ans = []

        for i in range(n - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue  # 固定的第一个数去重
            if nums[i] > 0:
                break     # 排序后不可能再凑到 0

            l, r = i + 1, n - 1
            while l < r:
                s = nums[i] + nums[l] + nums[r]
                if s < 0:
                    l += 1
                elif s > 0:
                    r -= 1
                else:
                    ans.append([nums[i], nums[l], nums[r]])
                    while l < r and nums[l] == nums[l + 1]:
                        l += 1
                    while l < r and nums[r] == nums[r - 1]:
                        r -= 1
                    l += 1
                    r -= 1
        return ans
```

时间 `O(n²)`；结果空间不计，排序还有实现相关的辅助空间（Python 的排序不能笼统宣称 `O(1)`）。

### 哈希法模板（用于理解 set 去重）

```python
def three_sum_hash(nums):
    nums.sort()
    ans = set()

    for i in range(len(nums) - 2):
        seen = set()
        for j in range(i + 1, len(nums)):
            need = -nums[i] - nums[j]
            if need in seen:
                ans.add((nums[i], need, nums[j]))
            seen.add(nums[j])

    return [list(x) for x in ans]
```

**注意**：

- `seen`：记录当前固定 `i` 后已经出现的数，防止同一位置重复使用。
- `ans`：`set` 存三元组，跨不同 `i` 去重。
- Python 的 `list` 不可哈希，不能加入 `set`；使用 `tuple`。
- 先检查 `need in seen`，再 `seen.add(nums[j])`。

## 5. 前后缀最值：接雨水

对每个下标 `i`，上方能存多少水，由它左侧（含自己）最高柱与右侧（含自己）最高柱中的较低者决定：

\[
water[i] = \min(leftMax[i], rightMax[i]) - height[i]
\]

### 预处理前缀/后缀最大值

```python
class Solution:
    def trap(self, height: list[int]) -> int:
        n = len(height)
        if n < 3:
            return 0

        left_max = [0] * n
        right_max = [0] * n
        left_max[0] = height[0]
        right_max[-1] = height[-1]

        for i in range(1, n):
            left_max[i] = max(left_max[i - 1], height[i])
        for i in range(n - 2, -1, -1):
            right_max[i] = max(right_max[i + 1], height[i])

        ans = 0
        for i in range(n):
            ans += min(left_max[i], right_max[i]) - height[i]
        return ans
```

时间 `O(n)`，额外空间 `O(n)`。

### 进一步优化：双指针 `O(1)` 空间

```python
def trap_two_pointers(height):
    l, r = 0, len(height) - 1
    lm = rm = ans = 0
    while l <= r:
        if height[l] <= height[r]:
            lm = max(lm, height[l])
            ans += lm - height[l]
            l += 1
        else:
            rm = max(rm, height[r])
            ans += rm - height[r]
            r -= 1
    return ans
```

**技巧**：前后缀数组是最容易理解的起点；掌握公式以后再学双指针压缩空间。

## 6. 堆：合并 K 个升序链表

### 核心思想

因为**每条链表本身有序**，全局最小的未使用节点，必定出现在每条链表当前的头节点中。

因此：

1. 初始化：每条非空链表只将**头节点**入堆；
2. 弹出全局最小节点，接到结果链表；
3. 将该节点的 `next` 入堆；
4. 重复直到堆为空。

**不要每轮扫描所有 `K` 条链表，也不要一次性清空堆。**

### Python 模板（`heapq` 不直接比较 ListNode）

```python
import heapq

class Solution:
    def mergeKLists(self, lists: list[Optional[ListNode]]) -> Optional[ListNode]:
        heap = []
        serial = 0

        for node in lists:
            if node is not None:
                heapq.heappush(heap, (node.val, serial, node))
                serial += 1

        dummy = ListNode(0)
        cur = dummy

        while heap:
            _, _, node = heapq.heappop(heap)
            nxt = node.next
            cur.next = node
            cur = node
            if nxt is not None:
                heapq.heappush(heap, (nxt.val, serial, nxt))
                serial += 1

        cur.next = None
        return dummy.next
```

这里 `serial` 保证两个节点 `val` 相等时，堆比较第二项整数，而不会尝试比较不可排序的 `ListNode` 对象。

复杂度：`N` 为总节点数，`K` 为链表数量；时间 `O(N log K)`（`K=0` 单独视为空输入），堆额外空间 `O(K)`。

### Java 写法

```java
PriorityQueue<ListNode> pq = new PriorityQueue<>(
    (a, b) -> Integer.compare(a.val, b.val)
);

for (ListNode node : lists) {
    if (node != null) pq.offer(node);
}

ListNode dummy = new ListNode(-1), cur = dummy;
while (!pq.isEmpty()) {
    ListNode node = pq.poll();
    cur.next = node;
    cur = cur.next;
    if (node.next != null) pq.offer(node.next);
}
cur.next = null;
return dummy.next;
```

## 7. 哈希表 + 双向链表：LRU 缓存

### 为什么必须组合两种结构

- `dict`：`key -> Node`，平均 `O(1)` 定位节点。
- 双向链表：已知节点时 `O(1)` 删除、插入。
- 链表头：最近使用；链表尾：最久未使用。
- 虚拟头尾节点（哨兵）可以统一边界处理。

**一次 `get` 命中，也算“使用”——必须移到头部。** `put` 更新已存在的键，同样要移到头部。

### 双向链表两套指针操作

```python
# 删除已知节点 x
x.prev.next = x.next
x.next.prev = x.prev

# x 插到 head 后面
x.next = head.next
x.prev = head
head.next.prev = x
head.next = x
```

### Python 面试标准模板

```python
class Node:
    def __init__(self, key=0, value=0):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.mp = {}
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def add_first(self, node):
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def get(self, key: int) -> int:
        if key not in self.mp:
            return -1
        node = self.mp[key]
        self.remove(node)
        self.add_first(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        if key in self.mp:
            node = self.mp[key]
            node.value = value
            self.remove(node)
            self.add_first(node)
            return

        node = Node(key, value)
        self.mp[key] = node
        self.add_first(node)
        if len(self.mp) > self.capacity:
            old = self.tail.prev
            self.remove(old)
            del self.mp[old.key]
```

`get/put` 平均 `O(1)`，空间 `O(capacity)`。

### Python 内置简洁解（理解后选用）

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.mp = OrderedDict()

    def get(self, key: int) -> int:
        if key not in self.mp:
            return -1
        self.mp.move_to_end(key)
        return self.mp[key]

    def put(self, key: int, value: int) -> None:
        if key in self.mp:
            self.mp.move_to_end(key)
        self.mp[key] = value
        if len(self.mp) > self.capacity:
            self.mp.popitem(last=False)
```

## 8. 二叉树递归的四个典型题目

### 总原则：先定义 `dfs(node)` 返回什么

典型后序遍历：

```python
def dfs(node):
    if node is None:
        return BASE
    left = dfs(node.left)
    right = dfs(node.right)
    # 处理当前节点，组合子树结果
    return COMBINE(left, right)
```

#### 8.1 中序遍历：左 → 根 → 右

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> list[int]:
        ans = []
        def dfs(node):
            if node is None:
                return
            dfs(node.left)
            ans.append(node.val)
            dfs(node.right)
        dfs(root)
        return ans
```

#### 8.2 翻转二叉树：递归 + 交换

```python
class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if root is None:
            return None
        self.invertTree(root.left)
        self.invertTree(root.right)
        root.left, root.right = root.right, root.left
        return root
```

要点：空树需要先返回；叶子节点不应被替换为 `None`；最后要返回 `root`。

#### 8.3 对称二叉树：镜像成对递归

```python
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        def mirror(a, b):
            if a is None and b is None:
                return True
            if a is None or b is None:
                return False
            return (a.val == b.val
                    and mirror(a.left, b.right)
                    and mirror(a.right, b.left))
        return root is None or mirror(root.left, root.right)
```

要点：不能只检查 `a.left ↔ b.right`，还必须检查 `a.right ↔ b.left`。

#### 8.4 二叉树直径：计算高度时顺便更新答案

**最值得反复理解的树形 DFS 技巧**：

- `dfs(node)` 的**返回值**是当前子树高度（按节点数）。
- `ans` 是所有节点中最大的 `左高度 + 右高度`（按边数）。
- 每个节点只访问一次，避免重复调用 `maxDepth`。

```python
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        ans = 0

        def dfs(node):
            nonlocal ans
            if node is None:
                return 0
            l = dfs(node.left)
            r = dfs(node.right)
            ans = max(ans, l + r)
            return max(l, r) + 1

        dfs(root)
        return ans
```

示例：

```text
        1
       / \
      2   3
     / \
    4   5

处理顺序（递归返回时）：4 → 5 → 2 → 3 → 1
节点 2：l=1,r=1, ans=2, 返回高度2
节点 1：l=2,r=1, ans=3, 返回高度3
答案=3（路径 4-2-1-3 的边数）
```

时间 `O(n)`，递归栈 `O(h)`，`h` 是树高。退化链式树可达 `O(n)` 栈深。原先“在每个节点再次求左右深度”的版本最坏 `O(n²)`。

isqrt(17)     # 4，整数平方根

### 9.8 递归、闭包与 Python 的 `self`

```python
class Solution:
    def outer_method(self, root):
        ans = 0
        def dfs(node):
            nonlocal ans  # 修改最近外层函数的局部绑定
            if node is None:
                return 0
            ans += 1
            return dfs(node.left) + dfs(node.right) + 1
        dfs(root)
        return ans
```

- 类成员方法互相调用：`self.dfs(...)`，不能直接写 `dfs(...)`（除非 `dfs` 是当前作用域内的局部函数）。
- 类实例属性访问：`self.head`，不是裸 `head`。
- Python 内部函数能调用同一作用域的 `dfs(...)`。
- `nonlocal` 修改外层函数变量；`global` 修改模块级变量。
- `True / False / None` 首字母大写。
- `__init__` 前后各两个下划线。

## 10. Java PriorityQueue 速查

```java
import java.util.PriorityQueue;
import java.util.Collections;

PriorityQueue<Integer> minHeap = new PriorityQueue<>();
PriorityQueue<Integer> maxHeap =
    new PriorityQueue<>(Collections.reverseOrder());

minHeap.offer(5);  // 入堆 O(log n)
minHeap.peek();    // 看堆顶 O(1)
minHeap.poll();    // 弹堆顶 O(log n)
minHeap.isEmpty();
minHeap.size();

PriorityQueue<ListNode> pq = new PriorityQueue<>(
    (a, b) -> Integer.compare(a.val, b.val)
);
```

比较器规则：返回负数，`a` 优先；返回正数，`b` 优先；返回 0，优先级相同。推荐 `Integer.compare(a.val,b.val)`，而不是直接相减，避免整数溢出。

**注意**：优先级队列只保证堆顶优先级正确，不保证直接遍历堆中的元素就是排序结果。

## 11. 本次刷题暴露的高频错误

| 错误 | 为什么错 | 正确做法 |
|---|---|---|
| `lmx = [height[0] * n]` | 创建了一个元素，不是长度为 `n` 的列表 | `[0] * n`，并设置边界值 |
| `range(n-2, -1)` | 默认正步长，反向循环不会执行 | `range(n-2, -1, -1)` |
| `foo(...)` 直接调用类方法 | Python 解析为局部/全局函数名 | `self.foo(...)` |
| `head.next` 在方法内直接使用 | `head` 没有定义为局部变量 | `self.head.next` |
| `true / false` | Python 区分大小写 | `True / False` |
| `_init_` | 不是特殊构造方法 | `__init__` |
| 定义 `value`，更新却用 `.val` | Python 可能静默创建新属性，旧值未改 | 属性命名保持一致 |
| `ans` 整数作为递归参数后修改 | 不会自动更新外层的那个整数变量 | `nonlocal`、`self.ans` 或明确返回答案 |
| 空节点前访问 `root.left` | 空树触发属性错误 | 先 `if root is None:` |
| LRU 淘汰节点时只改一侧指针 | 双向链表连接可能损坏 | 封装统一的 `remove(node)` |
| 一轮弹出堆中所有头节点 | 新产生的后继未参与这轮比较 | 每弹出一个节点，就把它的后继入堆 |
| 找到三数之和就直接加入列表 | 不同路径可能产生相同三元组 | 固定值去重、左右指针去重；或 `set(tuple)` |

**一个重要的 Python 细节**：函数体内的大部分名称/属性问题会在执行到那一行时才暴露；但语法错误通常在解析程序时就能发现。并且普通 Python 对象通常允许动态增加属性，所以 `.val` 与 `.value` 混用可能不报错，却导致逻辑错误。

## 12. 考前速记卡

| 题目 | 一句话核心思想 | 复杂度 |
|---|---|---|
| 下一个更大元素 | 单调栈：当前更大值出现时弹出并结算 | `O(n)` |
| 买卖股票 I | 维护历史最低买价，用当天价格尝试卖出 | `O(n)` |
| 三数之和 | 排序、固定一数、双指针、三处去重 | `O(n²)` |
| 接雨水 | 每格水量取左右最高柱中较小者减自身 | `O(n)` |
| 合并 K 个有序链表 | 堆中只保留每条链表当前候选头节点 | `O(N log K)` |
| LRU | `dict` 定位节点，双向链表维护新旧顺序 | 平均 `O(1)`/操作 |
| 二叉树中序遍历 | 左—根—右 | `O(n)` |
| 翻转二叉树 | 递归处理两侧，再交换指针 | `O(n)` |
| 对称二叉树 | 成对比较外侧与内侧镜像节点 | `O(n)` |
| 二叉树直径 | DFS 返回高度，顺便更新 `l+r` 的最大值 | `O(n)` |

### 最值得手写的 6 个模板

1. **单调栈**：`while st and ...: st.pop()`。
2. **排序 + 双指针**：固定一个数、左右夹逼、重复值跳过。
3. **前后缀最大值**：左右各扫一遍，再综合答案。
4. **堆归并**：入堆 K 个头节点，弹一个，补一个。
5. **LRU**：`remove`、`add_first`、`get`、`put` 四个动作。
6. **树形 DFS**：`left=dfs(left)`、`right=dfs(right)`、更新答案、返回子树信息。

> 核心学习方法：不要只背完整代码。先能解释「状态/变量表示什么」「为什么每次操作安全」「如何保证不遗漏、不重复」「时间复杂度为何成立」，再独立敲出模板。
