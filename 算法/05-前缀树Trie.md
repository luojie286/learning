# 05 · 前缀树（Trie）

> 一句话概括：多叉树，一条边代表一个字符，**根到某节点的路径 = 一个前缀**；查询「多少字符串以 s 为前缀」只走 |s| 步。
> ⚠️ 说明：原始记录为代码（`前缀树模板.cpp`），无文字笔记，正文解释为整理时补写。**原代码有一处越界 bug**，见「纠错」。

---

## 一、原理

**解决什么问题**：大量字符串的**前缀**匹配/统计——插入、查询都只与字符串长度有关，与字符串总数无关。

**静态数组实现**（竞赛常用，比指针版快且好写）：

- `t[p][c]`：节点 `p` 沿字符 `c` 走到的孩子编号（0 表示不存在）；根节点编号 0。
- `cnt[p]`：**经过**节点 p 的字符串个数 → 走完 s 的路径后，终点节点的 `cnt` = 「以 s 为前缀的字符串数」。
- `idx`：已分配的节点总数（新节点 `++idx`）。

```text
插入 "ab"、"ac"：
        根(0)
       a/  \c
      1     3
     b/      \
    2         4
cnt[1]=2, cnt[2]=1, cnt[3]=1, cnt[4]=1
查询前缀 "a"  → 走到节点1 → cnt=2 ✓
```

## 二、代码（原模板，加注释）

```cpp
int T, q, n, t[3000005][65], cnt[3000005], idx;
char s[3000005];

int getnum(char x) {           // 字符 → 0..61 的映射
    if (x >= 'A' && x <= 'Z') return x - 'A';
    else if (x >= 'a' && x <= 'z') return x - 'a' + 26;
    else return x - '0' + 52;  // 数字 52..61，共 62 种
}

void insert(char str[]) {
    int p = 0;                  // 从根出发
    for (int i = 0; str[i]; i++) {
        int c = getnum(str[i]);
        if (!t[p][c]) t[p][c] = ++idx;   // 没有这条边就建新节点
        p = t[p][c];
        cnt[p]++;               // 经过该节点的字符串数 +1
    }
}

int find(char str[]) {          // 返回以 str 为前缀的字符串个数
    int p = 0;
    for (int i = 0; str[i]; i++) {
        int c = getnum(str[i]);
        if (!t[p][c]) return 0; // 路断了：没有字符串有这个前缀
        p = t[p][c];
    }
    return cnt[p];
}
```

主流程：多组数据（`T` 组），每组先**清空** `t`、`cnt`、`idx` 再插入 n 个串、回答 q 个查询（即洛谷 P8306【模板】字典树题型）。

## 三、纠错：清空循环越界

> **原代码问题**：清空写的是 `for (j = 0; j <= 122; j++) t[i][j] = 0;`——但 `t` 的第二维只有 **65**，`j` 到 122 会**越界写**（写坏相邻行的内存，未定义行为；大概是把「ASCII 范围」和「映射后范围」记混了）。
> **正确理解**：`getnum` 映射后的范围是 0..61，清空 `j < 65` 即可。

```cpp
// 修正后的清空
for (int i = 0; i <= idx; i++) {
    for (int j = 0; j < 65; j++) t[i][j] = 0;   // 不是 j <= 122
    cnt[i] = 0;
}
idx = 0;
```

## 四、复杂度

| 操作 | 时间 | 空间 |
|---|---|---|
| 插入 / 查询一个串 | **O(|s|)** | — |
| 整棵树 | — | O(所有串总长 × 字符集 65) |

空间是 Trie 的代价——字符集大、串又长时数组可能开不下；只存小写字母时第二维开 26 即可。

---

## 📌 易错点

1. **多组数据不清空 / 清错范围**——`idx` 要归零，`t` 第二维按**映射后**的 65 清，不是 122（原代码实测逻辑错误）。
2. **`cnt` 语义**——它统计的是「**经过**该节点」的串数（前缀计数）；若要「**恰好等于**该串」的次数，应在串终点另设 `endCnt`。
3. **查询时路断要返回 0**，不能继续走下去。
4. **根节点是 0 且 `t[p][c]==0` 表示无边**——所以真实节点编号从 1 开始（`++idx`），别让 0 号当孩子。
