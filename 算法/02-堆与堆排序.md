# 02 · 堆与堆排序

> 一句话概括：堆是用**数组存的完全二叉树**（父 `(i-1)/2`，子 `2i+1` / `2i+2`），大顶堆堆顶最大；堆排序 = 建堆后不断取堆顶。
> ⚠️ 说明：原始记录为代码（`堆结构以及堆排序.cpp`），无文字笔记，正文解释为整理时补写。**原代码有两个实测确认的 bug**，见「纠错」节。

---

## 一、原理：数组怎么表示二叉树

```text
数组：[9, 7, 8, 4, 6, 3]
下标：  0  1  2  3  4  5

       9(0)
      /    \
    7(1)   8(2)
    /  \    /
  4(3) 6(4) 3(5)

父 = (i-1)/2    左子 = 2i+1    右子 = 2i+2
```

- **大顶堆**：任意父节点 ≥ 子节点 → `heap[0]` 是最大值（小顶堆反之）。
- **上浮 `heapifyUp`**：新元素加在数组尾部，与父节点比，比父大就交换，直到不再比父大（`push` 用）。
- **下沉 `heapifyDown`**：把堆顶换走后，新堆顶与**较大的孩子**比，比孩子小就交换，一路沉到底（`pop` 用）。
- **建堆 `buildHeap`**：从最后一个非叶节点 `size/2 - 1` 倒着到 0，逐个下沉——O(n)，比逐个 push 的 O(n log n) 快。

## 二、核心代码（保留原模板主干）

```cpp
template<typename T>
class Heap {
    std::vector<T> heap;
    bool isMaxHeap;                       // true 大顶堆

    void heapifyUp(int index) {
        if (index == 0) return;
        int parent = (index - 1) / 2;
        bool ok = isMaxHeap ? (heap[index] > heap[parent])
                            : (heap[index] < heap[parent]);
        if (ok) { std::swap(heap[index], heap[parent]); heapifyUp(parent); }
    }

    void heapifyDown(int index) {
        int left = 2 * index + 1, right = 2 * index + 2, target = index;
        if (left < (int)heap.size()) {
            bool ok = isMaxHeap ? (heap[left] > heap[target])
                                : (heap[left] < heap[target]);
            if (ok) target = left;
        }
        if (right < (int)heap.size()) {
            bool ok = isMaxHeap ? (heap[right] > heap[target])
                                : (heap[right] < heap[target]);
            if (ok) target = right;
        }
        if (target != index) {
            std::swap(heap[index], heap[target]);
            heapifyDown(target);
        }
    }

public:
    void push(const T& v) { heap.push_back(v); heapifyUp(heap.size() - 1); }

    T pop() {                             // 弹出堆顶：尾部元素顶替后下沉
        T top = heap[0];
        heap[0] = heap.back();
        heap.pop_back();
        if (!heap.empty()) heapifyDown(0);
        return top;
    }

    void buildHeap() {                    // O(n) 建堆：从最后非叶节点倒着下沉
        for (int i = (int)heap.size() / 2 - 1; i >= 0; i--) heapifyDown(i);
    }
};
```

## 三、两种堆排序（重点：方向别搞反）

### 写法一：弹出到新数组

不断 `pop()` 堆顶，按弹出顺序收集。**升序 → 用小顶堆**（每次弹最小）：

```cpp
template<typename T>
std::vector<T> heapSort(std::vector<T> arr, bool ascending = true) {
    Heap<T> heap(!ascending);            // ascending=true → 小顶堆 → 弹出即升序
    for (const auto& item : arr) heap.push(item);
    std::vector<T> result;
    while (!heap.empty()) result.push_back(heap.pop());
    return result;
}
```

### 写法二：原地排序（O(1) 额外空间）

**升序 → 用大顶堆**：每次把堆顶（当前最大）换到数组尾部，堆规模减一，再下沉修复：

```cpp
template<typename T>
void heapifyDown(std::vector<T>& arr, int start, int end, bool isMaxHeap);  // ①必须先声明！

template<typename T>
void heapSortInPlace(std::vector<T>& arr, bool ascending = true) {
    int n = arr.size();
    if (n <= 1) return;
    for (int i = n / 2 - 1; i >= 0; i--)
        heapifyDown(arr, i, n, ascending);      // ②升序 → 大顶堆（传 ascending）
    for (int i = n - 1; i > 0; i--) {
        std::swap(arr[0], arr[i]);              // 堆顶（最大）换到末尾
        heapifyDown(arr, 0, i, ascending);      // 堆规模缩为 i，修复
    }
}
```

> **记忆**：弹出式「小的先走」用**小**顶堆；原地式「大的沉底」用**大**顶堆。

## 四、纠错：原代码的两个 bug（均实测）

> ① 原文 `heapSortInPlace` 写在自由函数 `heapifyDown` **之前**且无前置声明——g++ 实测**编译错误**（`'heapifyDown' was not declared in this scope`）。修复：把 `heapifyDown` 定义（或声明）放到前面。
>
> ② 原文调用写的是 `heapifyDown(arr, i, n, !ascending)`——`ascending=true` 时建成了**小顶堆**，最小值被换到末尾，实测输出 `90 64 34 25 22 12 11 5`（**降序**）。修复：传 `ascending`，升序用大顶堆。上方代码已修正。
>
> 顺带：写法一的注释「创建大顶堆用于升序」与代码矛盾——代码 `!ascending`（小顶堆）才是对的，**注释错**。

## 五、复杂度与特性

| 操作 | 复杂度 |
|---|---|
| `push` / `pop` | O(log n) |
| `top` | O(1) |
| `buildHeap` | **O(n)** |
| 堆排序整体 | O(n log n)，原地版空间 O(1)，**不稳定** |

**与 STL 的关系**：`std::priority_queue<T>` 就是堆（默认大顶堆；小顶堆写 `priority_queue<int, vector<int>, greater<int>>`）——`算法/最小生成树 p算法模板.cpp` 的 Prim 正是这么用的。手写一遍的意义在于理解上浮/下沉，竞赛直接用 STL。

## 📌 易错点

1. **升序用哪种堆**——弹出到新数组：小顶堆；原地交换：大顶堆（方向相反，最易错）。
2. **`pop` 忘了用尾部元素顶替堆顶再下沉**——直接删掉 `heap[0]` 会破坏完全二叉树结构。
3. **模板函数先用后声明**——编译直接报错（原代码实测）。
4. **`buildHeap` 从 0 开始下沉**——应从 `size/2 - 1`（最后一个非叶节点）**倒序**开始。

## 🧠 速记口诀

```text
数组存完全二叉树：父 (i-1)/2，子 2i+1、2i+2
push 尾部上浮，pop 尾顶替顶再下沉
建堆 O(n)：从 n/2-1 倒序下沉
排序方向：弹出式小的先走用小堆；原地式大的沉底用大堆
```
