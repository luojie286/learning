# 04 · 并查集

> 一句话概括：用「代表元」表示集合——`find` 找根、`unite` 连根；配合路径压缩，近乎 O(1)。
> ⚠️ 说明：原始记录为代码（`并差集.cpp`，文件名是笔误，正确写法是**并查集**），正文解释为整理时补写。

---

## 一、原理

**解决什么问题**：动态维护「哪些元素属于同一组」，支持两种操作——

- `same(x, y)`：x 和 y 是否在同一集合？
- `unite(x, y)`：把 x 和 y 所在的两个集合合并。

**怎么表示集合**：每个集合是一棵「指向父亲的树」，**根节点 = 集合的代表元**。

```cpp
class DSU {
public:
    vector<int> parent;
    DSU(int n) {
        parent.resize(n + 1);
        for (int i = 0; i <= n; i++) parent[i] = i;   // 初始：人人自成一组
    }
    int find(int x) {
        if (parent[x] != x)
            parent[x] = find(parent[x]);   // 路径压缩：顺带把沿途节点直接挂到根
        return parent[x];
    }
    void unite(int x, int y) {
        parent[find(x)] = find(y);         // 把 x 的根挂到 y 的根下 → 两树合一
    }
    bool same(int x, int y) { return find(x) == find(y); }
};
```

**路径压缩**：`find` 递归回溯时把路径上每个节点直接改成指向根——下次再查就一步到底。只有路径压缩时，单次操作均摊近似 O(log n)；再配合**按秩/按高度合并**（见 `07` 修路作业的实现）可降到近乎常数（反阿克曼 α(n)）。

## 二、使用示例（原模板 main）

```cpp
int main() {
    int n, m;
    cin >> n >> m;
    DSU du(n);
    while (m--) {
        int opt; cin >> opt;
        int x, y; cin >> x >> y;
        if (opt == 1) cout << (du.same(x, y) ? "Yes" : "No") << endl;  // 查询
        else du.unite(x, y);                                           // 合并
    }
}
```

（即洛谷 P3367【模板】并查集的题型。）

## 三、它和谁搭伙

- **Kruskal 最小生成树**：按边权从小到大试加边，`same(u,v)` 判断「加这条边会不会成环」——并查集是 Kruskal 的发动机（→ `07-最小生成树.md`）。
- 连通性判定的通用工具：修路、社交网络关系传递、等价类合并。

---

## 📌 易错点

1. **`unite` 忘了先 `find`**——写 `parent[x] = y` 只是把叶子挪走，两棵树没合并。
2. **初始化忘了 `parent[i] = i`**——全 0 时 `find` 会死循环或查错。
3. **递归 `find` 在极深链上爆栈**——路径压缩前第一次查询可能退化成 O(n) 链；数据极大时可改迭代写法。
4. **只做路径压缩、不做按秩合并**——面试/考试要能说出「两个优化各自是什么」。

## 🧠 速记口诀

```text
并查集：根即代表元，find 查根，unite 接根
路径压缩：查一次，沿途全挂根
判连通、防成环（Kruskal）全靠它
```
