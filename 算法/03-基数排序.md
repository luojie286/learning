# 03 · 基数排序

> 一句话概括：按**位**从低到高，每位做一轮**稳定的计数排序**——LSD 基数排序。
> ⚠️ 说明：原始记录为代码（`基数排序模板.cpp`，含两处有价值的原注释），正文解释为整理时补写。

---

## 一、原理

**一句话理解**：不比较元素大小，而是「按个位排一轮、再按十位排一轮……」排完就有序。

**为什么必须稳定**：按第 `k` 位排序时，低 `k-1` 位**已经排好**，只有稳定才能保证这一轮不打破之前的成果——相等（当前位相同）的元素保持上一轮的相对顺序。这是基数排序正确性的全部秘密。

每轮（对某一位）就是一次**计数排序**：

1. `cnt[d]`：统计该位是 `d` 的元素个数（`d = a[i]/offset % 10`，即取出当前位）；
2. 前缀和：`cnt[d]` 变成「该位 ≤ d 的元素总数」→ 即该位为 d 的元素在输出数组中的**右端下标**（原注释：*计算前缀和，目的是确定数组应重排的区间*）；
3. **从后往前**遍历原数组，把每个元素放进 `help[--cnt[位]]`——倒序 + 前缀和从尾部递减，正好保证同一桶内**后出现的还在后面**（原注释：*从后往前保证相对次序，提高排序的稳定性*）。

## 二、代码（原模板，保留原注释）

```cpp
int main() {
    int n; cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    ll ma = *max_element(a, a + n);
    int offset = 1, bits = 0;
    while (ma) { ma /= 10; bits++; }        // 最大值有几位，就排几轮

    while (bits--) {
        vector<int> cnt(base, 0);
        for (int i = 0; i < n; i++)
            cnt[a[i] / offset % base]++;    // ① 取当前位，计数
        for (int i = 1; i < base; i++)
            cnt[i] += cnt[i - 1];           // ② 前缀和 → 每个桶的右端下标
        for (int i = n - 1; i >= 0; i--)
            help[--cnt[a[i] / offset % base]] = a[i];  // ③ 倒序放置（稳定）
        for (int i = 0; i < n; i++)
            a[i] = help[i];                 // ④ 拷回
        offset *= 10;                       // 下一位（十位、百位…）
    }
}
```

## 三、复杂度与适用

| 项 | 值 |
|---|---|
| 时间 | **O(d · (n + base))**，d = 最大位数 |
| 空间 | O(n + base) |
| 稳定性 | **稳定** |
| 限制 | 天然适合**非负整数**；负数要加偏移；浮点数/任意字符串需改造 |

**与比较排序的根本区别**：归并/快排/堆排基于「比较」，下界 O(n log n)；基数排序**不比较**，可以更快（d 小时近线性），代价是只适用于「能按位拆解」的关键字。

---

## 📌 易错点

1. **第③步从前往后放** ✗——必须**倒序**，否则同一桶内顺序颠倒、稳定性被破坏。
2. **忘做前缀和（第②步）**——`cnt` 只是个数，定不了放的位置。
3. **`offset` 忘乘 10**——每轮都在排个位，死循环排序无效。
4. **`bits` 求法在「最大值为 0」时**——`bits = 0`，一次都不排；数组全 0 恰好有序，没事，但要知道这个边界。
5. **有负数直接套** ✗——取位逻辑对负数失效，需先整体加偏移转非负。

---

## 🧠 速记口诀

```text
基数 = 按位多轮计数排序，低位到高位（LSD）
每轮三步：计数 → 前缀和 → 倒序放
稳定性是命根：这一轮不打乱上一轮
不比较，所以能冲破 O(n log n)
```
