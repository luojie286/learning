# 09 · 差分：等差数列的区间修改

> 一句话概括：普通区间加 = 差分数组改 2 个点 + 一次前缀和；**等差数列**区间加 = 二阶差分改 4 个点 + **两次**前缀和。
> ⚠️ 说明：原始记录为代码（`等差数列差分.cpp`），无文字笔记，正文解释为整理时补写。

---

## 一、先复习：普通差分

给区间 `[l, r]` 整体加 `s`，不必真加 r−l+1 次：

```cpp
d[l]   += s;      // 从 l 开始多出 s
d[r+1] -= s;      // 到 r+1 结束，把 s 还回去
// 最后做一次前缀和：a[i] = d[1] + ... + d[i]
```

**原理**：前缀和是差分的逆运算——区间加在「差分域」里只是两个点的突变。**多次修改、最后一次查询**的场景下，把 O(n·m) 降成 O(n+m)。

---

## 二、本题：区间加的是等差数列

把一段「首项 `s`、末项 `e`」的**等差数列**加到下标 `[l, r]` 上（公差 `d = (e−s)/(r−l)`）。

**思路推导**：

- 对原数组做一次差分：等差数列加进去后，差分数组在 `[l+1, r]` 内**多出常数 d**，只在两端 `l`、`r+1` 有突变；
- 「一段常数」还是区间加 → **对差分数组再做一次差分**（二阶差分），常数段也消失了，只剩 **4 个点**的突变。

即原代码注释的四句关键处理（题面下标从 1 计、答案数组 0 基）：

```cpp
ll d = (e - s) / (r - l);       // 公差

ans[l-1] += s;                  // 一阶差分的突变：起点出现 s
ans[l]   += d - s;              // 二阶差分：s 到 d 的跳变
ans[r]   -= e + d;              // 二阶差分：d 回落到 -e 的跳变（注意符号）
ans[r+1] += e;                  // 一阶差分的回补：终点后撤销 e
```

最后**做两次前缀和**（差分的逆 × 2），还原出真实数组：

```cpp
for (int i = 1; i < n; i++) ans[i] += ans[i-1];   // 第一次：一阶差分 → 数组
for (int i = 1; i < n; i++) ans[i] += ans[i-1];   // 第二次：二阶差分 → 一阶差分
```

**手工验证**（务必自己推一遍）：`n=5`，对 `[2,4]` 加首项 1、末项 3（d=1），期望位置 2、3、4 分别 +1、+2、+3：

```text
四点修改后：ans[1]+=1, ans[2]+=0, ans[4]-=4, ans[5]+=3
一次前缀和：1, 1, 1, -3（ans[5] 不参与）
二次前缀和：1, 2, 3, 0
→ 位置 p 的增量 = ans[p-1]：p=2→1, p=3→2, p=4→3 ✓
```

## 三、完整代码（原模板主干）

```cpp
void solve() {
    int n, m;
    cin >> n >> m;
    vector<ll> ans(n + 5, 0);          // 开大：要写 ans[r+1]

    while (m--) {
        int l, r; ll s, e;
        cin >> l >> r >> s >> e;
        if (l == r) {                  // 单点：公差无意义（除零），退化为普通差分
            ans[l-1] += s;
            ans[r]   -= s;
            continue;
        }
        ll d = (e - s) / (r - l);
        ans[l-1] += s;
        ans[l]   += d - s;
        ans[r]   -= e + d;
        ans[r+1] += e;
    }
    for (int i = 1; i < n; i++) ans[i] += ans[i-1];  // 两次前缀和还原
    for (int i = 1; i < n; i++) ans[i] += ans[i-1];

    ll mx = ans[0], xo = 0;
    for (int i = 0; i < n; i++) { mx = max(mx, ans[i]); xo ^= ans[i]; }
    cout << xo << " " << mx << '\n';   // 题目要求输出异或和与最大值
}
```

## 四、适用条件（重要）

差分适用于「**多次区间修改、最后一次性查询**」。如果修改和查询**交替**进行，前缀和一还原 O(n) 就白做了——那是线段树/树状数组的领域（后续学习）。

---

## 📌 易错点

1. **下标偏移**——本题输出是 0 基，位置 `p` 对应 `ans[p-1]`，四句修改的下标全部跟着偏一格，最容易错。
2. **`l == r` 忘特判**——`d = (e-s)/(r-l)` 除以 0；退化为两点普通差分。
3. **`ans[r] -= e + d` 的 `+d` 漏写**——这是二阶差分两个跳变合成的一项，漏了直接全盘错。
4. **只做一次前缀和**——二阶差分要**两次**才还原。
5. **数组开小**——会写 `ans[r+1]`，至少开到 `n+2`。

## 🧠 速记口诀

```text
普通区间加：两点 + 一次前缀和
等差区间加：四点（s、d−s、−e−d、e）+ 两次前缀和
一阶差分消区间，二阶差分消常数
边改边查别用差分，那是线段树的地盘
```
