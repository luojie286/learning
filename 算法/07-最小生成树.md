# 07 · 最小生成树（Kruskal 与 Prim）

> 一句话概括：连通带权无向图里挑 **n−1 条边**连通所有点且总权最小——Kruskal 按**边**贪心（排序 + 并查集），Prim 按**点**扩张（堆优化，形似 Dijkstra）。
> ⚠️ 说明：原始记录为两个模板（`最小生成树 k算法模板.cpp` / `p算法模板.cpp`），无文字笔记，正文解释为整理时补写。

---

## 一、问题定义

- **生成树**：连通所有 n 个点的 n−1 条边构成的树（不多不少，恰好无环）。
- **最小生成树（MST）**：所有生成树中边权总和最小的。
- 前提：图**连通**。不连通 → 选不满 n−1 条边 → 无解（两个模板都输出 `orz`）。

---

## 二、Kruskal：全局边贪心

**思路**：所有边按权值**从小到大**试；用并查集检查两端点是否已连通——已连通（`same`）就跳过（加上必成环），不连通就选入并 `unite`。选满 n−1 条结束。

```cpp
struct path { int u, v, weight; };

// DSU 定义见 04-并查集.md（find / unite / same）

sort(pathes.begin(), pathes.end(),
     [](const path& a, const path& b) { return a.weight < b.weight; });

int ans = 0, cnt = 0;
for (path x : pathes) {
    if (!du.same(x.u, x.v)) {   // 两端不连通才选（否则成环）
        du.unite(x.u, x.v);
        ans += x.weight;
        cnt++;
    }
}
if (cnt != n - 1) { cout << "orz" << endl; return; }  // 选不满 → 图不连通
cout << ans << endl;
```

> **纠错（原注释）**：原代码此处注释为「判断是否出现环（连通性检查）」——它真正检查的是**连通性**：选中的边数 `cnt < n-1` 说明图本身不连通，选不出生成树，与「出现环」无关（Kruskal 靠 `same` 跳过环边，根本不会选出环）。

复杂度：排序 O(m log m) + 并查集近似 O(m) → **适合稀疏图（边少）**。

---

## 三、Prim：从点扩张

**思路**：维护「已入树的点集」，每轮从**树外**的点中，选「离树最近」（连接树的边权 `dis` 最小）的那个入树——堆优化后写法和 Dijkstra 几乎一样，区别在于 `dis[v]` 存的是「v 连到树的**最小边权**」而非「到起点的路径长」。

```cpp
ll prim(int n, const vector<vector<pill>>& graph) {   // pill = pair<int,int>
    vector<int> dis(n + 1, INT_MAX);    // v 连接到 MST 的最小边权
    vector<bool> visit(n + 1, false);
    priority_queue<pill, vector<pill>, greater<pill>> pq;  // 小根堆 (边权, 节点)

    dis[1] = 0;
    pq.push({0, 1});

    ll ans = 0;
    int cnt = 0;                        // 已入树节点数

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (visit[u]) continue;         // 懒删除：过期堆项直接跳过
        visit[u] = true;
        cnt++;
        ans += d;
        for (auto [v, w] : graph[u])    // 用 u 的邻边松弛「到树的距离」
            if (!visit[v] && w < dis[v]) {
                dis[v] = w;
                pq.push({dis[v], v});
            }
    }
    return (cnt == n) ? ans : -1;       // 入不满 n 个点 → 不连通
}
```

**懒删除（lazy deletion）**：`dis[v]` 被更新更小后，堆里可能同时存在 v 的多个旧项；弹出时用 `visit[u]` 拦截已入树的。这是堆优化的通用技巧。

复杂度：O(m log m) → 边很多（**稠密图**）时也稳定；朴素 O(n²) 版对稠密图反而更优。

## 四、Kruskal vs Prim

| 对比项 | Kruskal | Prim |
|---|---|---|
| 贪心对象 | **边**（全局从小到大挑） | **点**（每次并入离树最近的点） |
| 核心依赖 | 排序 + **并查集** | 距离数组 + **堆** |
| 复杂度 | O(m log m) | 堆版 O(m log m)，朴素 O(n²) |
| 适合 | **稀疏图** | **稠密图**（朴素版） |
| 输出不连通 | 选中边数 < n−1 | 入树点数 < n |

**共同点**：都是贪心；都能证明正确（切分定理）；结果总权和相同（MST 不唯一时边集可能不同，总权一样）。

## 五、综合练习：修路作业（原 `作业/修路.cpp`）

这道作业 = **Kruskal + 三个加强点**，非常值得复盘：

1. **并查集加了「按高度合并」**：矮树挂到高树下，两边同高时树高 +1——控制树高，避免退化成链（对应 `04` 提到的按秩合并）：

```cpp
void unite(int x, int y) {
    int rootX = find(x), rootY = find(y);
    if (rootX == rootY) return;
    if (height[rootX] < height[rootY])      parent[rootX] = rootY;
    else if (height[rootX] > height[rootY]) parent[rootY] = rootX;
    else { parent[rootY] = rootX; height[rootX]++; }
}
```

2. **边排序没用 `sort`，而是手写了归并排序**（`mysort` / `merge`，思想见 → `01-归并排序.md`）——练手归并的好场景。
3. **`unordered_map` 离散化**：村庄编号可能是任意整数，`mp[x]` 把原始编号映射成 0,1,2… 再进并查集数组。

主流程与 Kruskal 模板完全一致：边按权排序 → `same` 跳过 / `unite` 选入 → `cnt != n-1` 输出「不连通」。

---

## 📌 易错点

1. **Kruskal 忘了 `same` 检查**——把环边也选进去，总权和偏大。
2. **`cnt != n-1` 的含义**——是「图不连通、选不满」，不是「出现环」（原注释误导）。
3. **Prim 的 `dis` 语义**——是「该点到**树**的最小边权」，不是 Dijkstra 的「到起点距离」；松弛条件是 `w < dis[v]`，不要写成 `d + w < dis[v]`。
4. **堆优化忘了懒删除**（`if (visit[u]) continue;`）——同一节点重复入树，答案翻倍。
5. **无向图邻接表要加两条边**（`graph[x].push_back({y,z})` 和 `graph[y].push_back({x,z})`）——只加一条方向就错了。

---

## 🧠 速记口诀

```text
MST：n 个点 n−1 条边，总权最小，前提图连通
Kruskal 挑边：边排序，same 跳环，unite 收编；稀疏图友好
Prim 挑点：谁离树最近谁进来，堆里懒删除；稠密图友好
选不满 n−1 条 = 不连通，不是成环
```
