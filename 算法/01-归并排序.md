# 01 · 归并排序

> 一句话概括：**分治**——递归把数组拆成两半，再用双指针把两个有序段合并成一个有序段。
> ⚠️ 说明：原始记录为代码模板（`归并排序.cpp`），无文字笔记，正文解释为整理时补写。

---

## 一、原理

```text
mergesort(l, r)
  ├─ 递归排左半 mergesort(l, mid)
  ├─ 递归排右半 mergesort(mid+1, r)
  └─ merge(l, mid, r)：合并两个已排好的段
```

**merge 的关键**：两段各自有序，用双指针 `i`（左段）、`j`（右段）每次取较小者放入辅助数组 `help`——「两个有序数组合并」是归并排序的核心动作，也是很多题（逆序对、合并区间）的基础。

**为什么需要 `help` 辅助数组**：直接往原数组 `a` 里写会覆盖还没比较的元素；先写进 `help[l..r]`，最后整体拷回。

---

## 二、代码（原模板，加注释）

```cpp
void merge(int a[], int l, int m, int r) {
    int i = l, j = m + 1;
    int index = 0;
    while (i <= m && j <= r) {
        if (a[i] <= a[j]) {          // <= ：相等时先取左边 → 保证稳定性
            help[index + l] = a[i]; i++; index++;
        } else {
            help[index + l] = a[j]; j++; index++;
        }
    }
    while (i <= m) { help[index + l] = a[i]; i++; index++; }  // 左段剩余
    while (j <= r) { help[index + l] = a[j]; j++; index++; }  // 右段剩余
    for (int i = l; i <= r; i++) a[i] = help[i];              // 拷回原区间
}

void mergesort(int a[], int l, int r) {
    if (l == r) return;              // 一个元素天然有序（递归终点）
    int mid = l + (r - l) / 2;       // 防溢出写法（int 相加可能溢出）
    mergesort(a, l, mid);
    mergesort(a, mid + 1, r);
    merge(a, l, mid, r);
}
```

## 三、复杂度与特性

| 项 | 值 | 说明 |
|---|---|---|
| 时间 | **O(n log n)**，最好最坏都一样 | 每层合并 O(n)，共 log n 层 |
| 空间 | O(n) | `help` 辅助数组 |
| 稳定性 | **稳定** | 靠 `a[i] <= a[j]` 的 `=` |

**与其他排序的关系**：和快排同属 O(n log n) 的分治，但归并**稳定**、最坏不退化；代价是 O(n) 额外空间。三者对比总表见 → `00-总览与速记.md`。

**merge 思想的复用**：`作业/修路.cpp` 里手写归并对**边数组**按权值排序；逆序对计数（归并时统计右段先被取走的次数）是经典后续应用。

---

## 📌 易错点

1. **`help` 的下标**：写回区间是 `[l, r]`，不是 `[0, n-1]`——递归每层只处理自己的段。
2. **`a[i] <= a[j]` 写成 `<`**——仍能排对，但**稳定性丢了**（相等元素右段会先入）。
3. **`mid = (l+r)/2` 潜在溢出**——`l + (r-l)/2` 更安全（竞赛中 l、r 都很大时）。
4. **忘写两个「扫尾」while**——剩余段的元素必须接在后面。

---

## 🧠 速记口诀

```text
归并 = 递归拆两半 + 双指针合一
拆到 l==r 为止；merge 借 help，最后拷回 [l, r]
相等取左保稳定；O(n log n) 稳，代价 O(n) 空间
```
