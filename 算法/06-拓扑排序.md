# 06 · 拓扑排序

> 一句话概括：不断「摘掉」入度为 0 的点（没有前置依赖的点），摘的顺序就是拓扑序；摘不完 = 图里有环。
> ⚠️ 说明：原始记录为代码（`拓扑排序.cpp`，原文件注释「拓扑排序本质是 BFS」——不完全准确，见下），正文解释为整理时补写。

---

## 一、原理

**解决什么问题**：有向无环图（DAG）上排「依赖顺序」——课程先修、任务调度、编译依赖。

**Kahn 算法**（本模板用的就是它）：

1. 统计每个点的**入度**（有几条边指向它 = 有几个前置依赖）；
2. 所有**入度 0** 的点入队（没有依赖，可以先做）；
3. 出队一个点 p 放进答案，并把 p 指向的每个点 `x` 入度 `-1`（p 完成后，x 少一个依赖）；
4. x 的入度减到 0 就入队；
5. 结束时：**答案个数 = n → 无环，得到拓扑序；< n → 有环**（环上点入度永远减不到 0）。

```text
A → B → C
A → C

入度：A=0, B=1, C=2
先摘 A（B、C 各减 1）→ 摘 B（C 减 1）→ 摘 C
```

> **纠错**：原注释「拓扑排序本质是 BFS」不严谨——Kahn 算法**用队列实现、形式像 BFS**，但思想是**入度削减**，与「按层扩展」的 BFS 是两回事。另外拓扑序也能用 DFS 求（后序遍历的逆序），那是另一种做法。

## 二、代码（原模板，删去注释掉的模板代码，加注释）

```cpp
int main() {
    vector<int> ans;
    int n, m;
    cin >> n >> m;
    vector<vector<int>> grap(n + 1, vector<int>());  // 邻接表
    vector<int> cnt(n + 1, 0);                       // 入度表
    queue<int> q;

    while (m--) {
        int u, v;
        cin >> u >> v;
        grap[u].push_back(v);   // 边 u → v
        cnt[v]++;               // v 的前置依赖 +1
    }

    for (int i = 1; i <= n; i++)
        if (cnt[i] == 0) q.push(i);      // 无依赖的点先入队

    while (!q.empty()) {
        int p = q.front(); q.pop();
        ans.push_back(p);                // 摘掉 p
        for (int x : grap[p]) {
            if (--cnt[x] == 0)           // p 完成，x 少一个依赖
                q.push(x);               // 依赖清零 → x 可做
        }
    }

    if (ans.size() != n) cout << -1 << endl;   // 摘不完 = 有环
    else { /* 输出 ans */ }
}
```

## 三、要点

- **拓扑序不唯一**：多个入度 0 的点同时可选时，顺序取决于入队顺序（要求字典序最小就用小根堆代替队列）。
- **拓扑排序是 DAG 的判定器**：能排完 ⇔ 无环。这也是「判断有向图是否有环」的标准做法。
- **与并查集的分工**（易混）：并查集判**无向图**连通性；拓扑排序判**有向图**有无环。并查集不能处理有向依赖。

| | 拓扑排序 | 并查集 |
|---|---|---|
| 图类型 | 有向（DAG） | 无向 |
| 回答的问题 | 依赖顺序 / 有无环 | 连通性 / 合并集合 |
| 边的方向 | 关键信息 | 忽略方向 |

---

## 📌 易错点

1. **入度初始化后忘了把入度 0 的点入队**——队列起不来，直接输出有环。
2. **`--cnt[x]` 后判断 `== 0` 才入队**——不是减完就入，减到 0 才表示依赖清空。
3. **用拓扑排序判无向图环** ✗——方向信息丢了；无向图判环用并查集（加边两端已连通 ⇒ 成环）。
4. **以为拓扑序唯一**——通常有多个合法序。

## 🧠 速记口诀

```text
拓扑 = 摘入度为零的点；摘一个，邻点入度减一
减到零就进队；摘不完 = 有环
Kahn 是入度削减，不是真 BFS
有向判环用拓扑，无向判环用并查集
```
