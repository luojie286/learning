# 项目启动与关闭操作手册

> 项目：智能园区餐饮 Agent 平台  
> 适用环境：Windows、IntelliJ IDEA、Windows MySQL、Docker Redis、Nginx  
> 整理日期：2026-10-12

## 1. 服务关系

项目运行时涉及以下服务：

```text
浏览器
  ↓
Nginx（前端静态文件和反向代理）
  ↓
Spring Boot（127.0.0.1:8080）
  ├─ MySQL（127.0.0.1:3306）
  └─ Redis（Docker容器 campus-redis，127.0.0.1:6379）
```

推荐启动顺序：

```text
MySQL
  ↓
Docker Desktop
  ↓
Redis容器
  ↓
Spring Boot后端
  ↓
Nginx
  ↓
浏览器访问前端
```

## 2. 启动 MySQL

以管理员身份打开 PowerShell，查询实际服务名：

```powershell
Get-Service *mysql*
```

假设查询到的服务名是 `MySQL80`：

```powershell
Start-Service -Name MySQL80
```

如果实际名称是 `MySQL84` 或其他名称，请使用查询结果中的 `Name`。

确认服务状态：

```powershell
Get-Service -Name MySQL80
```

正常状态：

```text
Running
```

也可以检查数据库端口：

```powershell
Test-NetConnection 127.0.0.1 -Port 3306
```

正常结果包含：

```text
TcpTestSucceeded : True
```

## 3. 启动 Redis

### 3.1 启动 Docker Desktop

打开 Docker Desktop，等待 Docker Engine 完全启动。

### 3.2 启动已有 Redis 容器

```powershell
docker start campus-redis
```

正常会返回：

```text
campus-redis
```

### 3.3 验证 Redis

```powershell
docker exec campus-redis redis-cli ping
```

正常返回：

```text
PONG
```

不需要再次执行 `docker run`。`campus-redis` 已经创建，平时只需 `start` 和 `stop`。

## 4. 启动 Spring Boot 后端

使用 IntelliJ IDEA 打开项目：

```text
E:\codex\Roger001
```

在 IDEA 右上角确认运行配置为：

```text
SkyApplication
```

点击绿色 Run 按钮。

控制台正常日志应包含：

```text
The following 1 profile is active: "local"
Tomcat started on port 8080
Started SkyApplication
```

后端健康检查地址：

```text
http://127.0.0.1:8080/api/health
```

注意：

- 应运行 `SkyApplication`；
- 不要运行 `PasswordGenerator`；
- `PasswordGenerator` 只是用于生成初始 BCrypt 密码哈希的临时工具。

## 5. 启动 Nginx

打开 PowerShell，进入 Nginx 安装目录：

```powershell
cd D:\Nginx\nginx
```

检查配置：

```powershell
.\nginx.exe -t
```

正常结果：

```text
syntax is ok
test is successful
```

启动 Nginx：

```powershell
.\nginx.exe
```

检查进程：

```powershell
Get-Process nginx -ErrorAction SilentlyContinue
```

通常会看到两个 Nginx 进程：一个主进程和一个工作进程。

PowerShell 不会默认运行当前目录中的程序，因此必须写：

```powershell
.\nginx.exe
```

不能只写：

```powershell
nginx.exe
```

## 6. 打开前端并登录

浏览器访问：

```text
http://127.0.0.1/
```

管理端测试账号：

```text
用户名：admin
密码：admin123
```

不要使用下面的地址寻找前端页面：

```text
http://127.0.0.1:8080/
```

`8080` 是 Spring Boot 后端端口，而且后端没有定义根路径 `/`。

## 7. 常用访问地址

| 地址 | 用途 |
| --- | --- |
| `http://127.0.0.1/` | Nginx托管的前端页面 |
| `http://127.0.0.1:8080/api/health` | 直接检查 Spring Boot |
| `POST http://127.0.0.1:8080/api/admin/employee/login` | 直接访问后端登录接口 |
| `POST http://127.0.0.1/api/admin/employee/login` | 通过 Nginx 访问登录接口 |

本项目的 Spring Boot 绑定 `127.0.0.1`。部分 Windows 环境可能把 `localhost` 优先解析为 IPv6 的 `::1`，因此本地调试优先使用 `127.0.0.1`。

## 9. 日常启动时不需要重复的工作

以下工作只在初始化或相关内容变化时执行，日常启动不需要重复：

- 不需要重新执行建表 SQL；
- 不需要重新插入管理员账号；
- 不需要重新生成 BCrypt 密码；
- 不需要重新创建 Redis 容器；
- 前端代码没有变化时，不需要重新执行 `npm run build`；
- Nginx配置没有变化时，不需要重新配置；
- 后端依赖没有变化时，不需要重新导入 Maven 项目。

MySQL数据保存在数据库中；停止服务不会删除表。Redis容器停止后仍然存在；再次执行 `docker start campus-redis` 即可恢复运行。

## 10. 推荐关闭顺序

### 10.1 停止 Spring Boot

在 IDEA 的 Run 窗口点击红色停止按钮，或者按：

```text
Ctrl + F2
```

### 10.2 停止 Nginx

```powershell
cd D:\Nginx\nginx
.\nginx.exe -s quit
```

如果 `logs/nginx.pid` 丢失，但 Nginx进程仍然存在：

```powershell
Stop-Process -Name nginx
```

确认：

```powershell
Get-Process nginx -ErrorAction SilentlyContinue
```

没有输出表示已经停止。

### 10.3 停止 Redis

```powershell
docker stop campus-redis
```

这只会停止容器，不会删除容器和数据。

### 10.4 停止 MySQL

以管理员身份运行 PowerShell。假设服务名为 `MySQL80`：

```powershell
Stop-Service -Name MySQL80
```

确认：

```powershell
Get-Service -Name MySQL80
```

状态为 `Stopped` 表示已经关闭。

如果当前位于 `mysql>` 命令行，输入：

```sql
exit;
```

只会退出 MySQL客户端，不会停止数据库服务器。

## 11. 一页式命令速查

### 启动

```powershell
# 管理员 PowerShell：使用实际 MySQL 服务名
Start-Service -Name MySQL80

# Docker Desktop 启动完成后
docker start campus-redis
docker exec campus-redis redis-cli ping

# 在 IDEA 中运行 SkyApplication

# 普通 PowerShell
cd D:\Nginx\nginx
.\nginx.exe -t
.\nginx.exe
```

### 关闭

```powershell
# 先在 IDEA 中停止 SkyApplication

cd D:\Nginx\nginx
.\nginx.exe -s quit

docker stop campus-redis

# 管理员 PowerShell：使用实际 MySQL 服务名
Stop-Service -Name MySQL80
```
