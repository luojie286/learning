# 项目学习目录说明

> 这里是**跟着项目课程学做真实后端项目**的材料区，与根目录的按主题整理的知识笔记（java/、计算机网络/ 等）定位不同：
> 知识笔记回答"某个知识点是什么"，这里回答"在一个真实项目里怎么落地"。

## 目录结构

```text
项目学习/
├── 智能园区点餐功能/          ← 跟着《苍穹外卖》课程做的园区点餐系统（Spring Boot 3 + MySQL + Redis）
│   ├── 讲义/讲义/day01~day12/  ← 课程讲义（md + 截图 assets）
│   ├── 资料/资料/              ← 课程配套资源（nginx 前端环境、原型、安装包等）
│   ├── 登录功能的总结.md        ← 自己的实践笔记：登录 + JWT 拦截器落地
│   ├── 启动项目服务流程.md      ← 自己的实践笔记：nginx/MySQL/Redis/后端 的启动顺序
│   └── jwt.txt                 ← 空文件，预留
└── 临时代码试验区/             ← 随手试代码的地方（目前为空）
```

## 与知识笔记的对应关系

| 项目实践 | 对应主题笔记 |
|---|---|
| 登录 + JWT 拦截器 + BaseContext | `java/34-密码安全与JWT鉴权.md` |
| Nginx 前端反向代理 | `java/28-Tomcat与Servlet及Nginx.md` |
| Controller/Service/Mapper 分层 | `java/25`-`31` |
| MySQL 建表 + 索引 | `java/32-MySQL基础.md` |

## ⚠️ 约定

- 安装包（.exe）已加入 `.gitignore`，不进 GitHub——软件从官网重新下载即可，仓库只存学习材料。
- 数据库密码等敏感信息**不写进任何 md 文件**；`jwt.txt` 保持空文件或只放本地临时内容。
