# 01 · 计算机网络概述与体系结构

> 一句话概括：网络 = **主机 + 交换设备 + 链路**，按拓扑和覆盖范围分类，通过**分层体系结构**（OSI / TCP-IP）来组织协议。

## 一、计算机网络的基本概念

> 原始记录：`1.1 计算机网络的基本概念`（仅标题）

**计算机网络** = 将地理位置不同的、具有独立功能的多台计算机（及其外部设备），通过**通信线路与设备**连接起来，在**网络协议**和软件的管理协调下，实现**资源共享与信息传递**的系统。

三个关键点，缺一不可：

1. **多台独立主机**（不是一台机器的多个终端）
2. **有通信链路与设备**把它们连起来
3. **遵循统一协议**，才能互相理解

---

## 二、计算机网络的功能

> 原始记录：数据通信、资源共享、并行与分布式处理、可靠性、可扩充性

| 功能 | 说明 |
|---|---|
| **数据通信** | 最基本的功能——文件传输、邮件、即时通信 |
| **资源共享** | 硬件（打印机、存储）、软件、**数据**资源都能共享 |
| **并行与分布式处理** | 一个任务拆给多台机器同时算，提升整体算力 |
| **可靠性** | 多台机器互为备份，单点故障不至于整体瘫痪 |
| **可扩充性** | 需要更强能力时，往网络里加机器即可，不必换整机 |

> **数据通信是基础，资源共享是目的。**

---

## 三、计算机网络的组成

> 原始记录：资源子网、通信子网

从功能上把网络拆成两半：

```text
资源子网（上层）   提供资源的主机、终端、软件、数据
      ↑↓
通信子网（下层）   路由器、交换机、通信线路 —— 负责数据的传输与转发
```

- **资源子网**：面向用户，负责**处理与提供资源**
- **通信子网**：面向传输，负责**把数据从 A 送到 B**，不关心内容

> 这个划分的意义在于**分层解耦**：上层换什么业务，下层只管传；下层换什么技术，上层不受影响。

---

## 四、计算机网络的拓扑结构

> 原始记录：网状、星状、树状、总线型、环状、混合型

| 拓扑 | 结构 | 优点 | 缺点 |
|---|---|---|---|
| **总线型** | 所有节点挂在一条公共总线上 | 结构简单、布线省 | 总线断了全网瘫；冲突多 |
| **星状** | 所有节点连到中心节点 | 管理方便、单点故障好隔离 | 中心节点是单点瓶颈/故障点 |
| **环状** | 节点首尾相连成环 | 传输时延确定 | 单点故障易影响全环 |
| **树状** | 星状的层叠扩展 | 易于分级管理、扩展 | 根节点故障影响大 |
| **网状** | 节点间多路径互联 | **可靠性最高、冗余强** | 布线成本最高、结构最复杂 |
| **混合型** | 以上多种组合 | 兼顾成本与性能 | 设计与维护复杂 |

> 现实中的网络基本都是**混合型**：局域网常用星状（交换机为中心），骨干网用网状。

## 五、计算机网络的分类

> 原始记录：个人域网、局域网、城域网、广域网

**按覆盖范围**从小到大：

| 类型 | 全称 | 覆盖范围 | 典型例子 |
|---|---|---|---|
| **PAN** | 个人域网 | 几米 | 蓝牙耳机、手机与手表互联 |
| **LAN** | 局域网 | 一栋楼 / 一个园区 | 家庭 Wi-Fi、公司内网、机房里 |
| **MAN** | 城域网 | 一个城市 | 城市宽带骨干、有线电视网 |
| **WAN** | 广域网 | 跨城市 / 国家 / 全球 | 互联网本身 |

> 记忆锚点：**PAN 米级 → LAN 楼级 → MAN 城级 → WAN 国家级**。

## 六、计算机网络的体系结构

> 原始记录：`1.4 计算机网络体系结构`（仅标题）

网络通信极其复杂，解决办法是**分层**：每一层只解决一类问题，只依赖下一层提供的服务。

```text
OSI 七层（理论模型）        TCP/IP 四层（实际使用）
┌──────────────┐          ┌──────────────┐
│  应用层       │          │              │
│  表示层       │  ──────→ │   应用层      │
│  会话层       │          │              │
├──────────────┤          ├──────────────┤
│  传输层       │  ──────→ │   传输层      │   TCP / UDP
├──────────────┤          ├──────────────┤
│  网络层       │  ──────→ │   网际层      │   IP
├──────────────┤          ├──────────────┤
│  数据链路层   │  ──────→ │              │
│  物理层       │          │  网络接口层   │
└──────────────┘          └──────────────┘
```

| 层 | 干什么 | 关键词 |
|---|---|---|
| 应用层 | 面向具体业务 | HTTP、FTP、DNS、SMTP |
| 传输层 | **进程到进程**的通信 | TCP（可靠）、UDP（快） |
| 网络层 | **主机到主机**、跨网络寻址路由 | IP、路由器 |
| 数据链路层 | 相邻节点间的帧传输 | 以太网、交换机、MAC |
| 物理层 | 比特流在介质上传输 | 网线、光纤、电信号 |

**为什么要分层**：各层独立演进（换成 Wi-Fi 不影响 HTTP）、便于分工实现、便于排错定位。

---

## 📌 易错点

1. **把「资源子网 / 通信子网」和「OSI 分层」混为一谈**——前者是功能上的两大块，后者是协议的层次划分，不是一回事。
2. **认为星状网比网状网更可靠**——星状的中心节点是单点故障；网状网冗余路径最多，可靠性最高。
3. **OSI 是七层、TCP/IP 是四层，别对着数**——OSI 的上三层（应用/表示/会话）在 TCP/IP 里合并为一个应用层。
4. **把「网络层」和「传输层」的职责搞反**——网络层负责**主机到主机**（IP），传输层负责**进程到进程**（端口）。
5. **以为交换机和路由器是同类东西**——交换机工作在链路层（同一个网络内部转发），路由器工作在网络层（跨网络选路）。
6. **把「互联网」当成「互联网的物理网络」**——Internet 指全球最大的那个特定网络，internet 泛指互联的网络，翻译时容易混。

## 🧠 速记口诀

```text
网络三要素：多台独立主机 + 通信链路设备 + 统一协议
五大功能：通信、共享、并行分布式、可靠、可扩充
两子网：资源子网管处理，通信子网管传输
拓扑六种：总线、星、环、树、网状、混合；网状最可靠，星状最常用
范围四档：PAN 米、LAN 楼、MAN 城、WAN 国
分层：应用层业务、传输层进程到进程（TCP/UDP）、网络层主机到主机（IP）、链路层相邻节点、物理层比特流
```
