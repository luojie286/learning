# 05 · 面向对象

> 一句话概括：Java OOP 的核心是「字段看引用，方法看对象」。

---

## 一、继承的对象结构：`new Dog()` 是什么

```java
class Animal {
    int age;
    void eat() {}
}

class Dog extends Animal {
    String name;
    void bark() {}
}

Dog d = new Dog();
```

### 关键理解

- `new Dog()` 在堆中创建的是 **一个 Dog 对象**
- **父类的实例字段也属于这个 Dog 对象的一部分**（Animal 的 `age` 也在这个 Dog 对象里）
- **方法不会随着每次 `new` 被复制到对象中**——方法由类层面的元数据描述
- 类的方法、字段信息、继承关系都由类的元数据管理

### 不要理解成

> ❌ "Dog 对象里又单独 new 了一个 Animal 对象。"

### 准确理解

> ✅ "Dog 对象包含从 Animal 继承来的实例状态，Dog 与 Animal 的方法实现由类层面的元数据管理。"

## 二、父类引用指向子类对象

```java
Animal a = new Dog();
```

这里有两种「类型」：

| 类型 | 含义 |
|------|------|
| **编译时类型**（引用的静态类型） | `Animal`（看变量声明） |
| **运行时类型**（对象的实际类型） | `Dog`（看 `new` 后面） |

```java
a.eat();  // 如果 Dog 重写了 eat()，调用 Dog.eat() —— 这就是多态
```

## 三、字段没有多态（最重要的一条）

**字段和方法要分开理解。**

```java
class Animal {
    int age = 10;
}
class Dog extends Animal {
    int age = 20;
}

Animal a = new Dog();
Dog    d = new Dog();

System.out.println(a.age);  // 10 ← 看引用类型
System.out.println(d.age);  // 20 ← 看引用类型
```

### 原因

> **字段访问主要根据引用的编译时类型确定，不存在方法那样的动态多态。**

子类声明与父类同名字段，严格叫：

> **字段隐藏（field hiding）**，不是字段重写。

### 一句话记忆

> **方法看对象，字段看引用类型。**

## 四、JVM 字节码：`invokevirtual` 和 `invokespecial`

普通实例方法调用涉及：

```
invokevirtual   ← 与虚方法动态分派相关（普通实例方法）
```

特殊调用使用：

```
invokespecial   ← 主要用于：
                · 构造方法 <init>
                · super.xxx()
                · private 方法等
```

```java
Dog() {
    super();  // 父类构造调用是 invokespecial
}
```

创建 Dog 对象的调用链：

```
Dog.<init>
   ↓
Animal.<init>
```

## 五、方法重写的访问权限

**核心规则**：子类重写时**可以扩大访问权限，不能缩小**。

```java
class Animal {
    protected void eat() {}   // protected
}
class Dog extends Animal {
    public void eat() {}      // ✅ public（扩大）
}
// private void eat() {}      // ❌ 缩小了，禁止
```

### 访问权限从窄到宽

```
private
  ↓
默认（package-private）
  ↓
protected
  ↓
public
```

### 重写规则速记

> 可以扩大（private → public），不能缩小（public → private）。

## 六、方法重写的返回值类型

### 6.1 基本类型

必须**完全相同**。

```java
class Animal {
    int get() { return 0; }
}
// 不能重写成
class Dog extends Animal {
    long get() { return 0; }   // ❌
}
```

### 6.2 引用类型：协变返回（covariant return）

允许返回**更具体的子类型**：

```java
class Animal {
    Animal get() { return new Animal(); }
}
class Dog extends Animal {
    @Override
    Dog get() { return new Dog(); }   // ✅ 合法（Dog 是 Animal 的子类）
}
```

### 一句话记忆

> **基本类型必须相同，引用类型可以协变。**

---

## 📌 易错点

1. **「字段没有多态」** 是最容易踩的坑。看到 `Animal a = new Dog();` 时：
   - 方法调用看运行时对象
   - **字段访问看引用类型（编译时类型）**
2. **重写时缩小权限会编译失败**——`public → private` 不行。
3. **基本类型重写不能改类型**——`int → long` 不算协变，编译错。
4. **引用类型协变返回** 只在重写时有效，普通方法返回类型不能这么写。
5. **`@Override` 注解** 是**强烈建议**写的——写了编译器会帮你检查签名是否真的匹配父类，避免笔误。
6. **`static` 方法不存在重写**，只存在隐藏（子类 static 方法会隐藏父类 static 方法，调用哪个看引用类型）。

---

## 🧠 速记口诀

```
字段看引用，方法看对象
权限可以大不能小，重写返回基类同、引用可协变
普通方法 invokevirtual，super/private 用 invokespecial
```
