# 03 · 字符串与构建器

> 一句话概括：String 不可变，拼接请用 StringBuilder，相等请用 equals。

---

## 一、String 的不可变性

字符串对象本身**不可修改**，但可以改变变量的指向：

```java
String greeting = "Hello";
greeting = greeting.substring(0, 3) + "p!";   // "Help!"
```

本质：`substring` + 拼接会在**新的内存空间**创建一个 String 对象，然后让 `greeting` 改为指向它。原来的 `"Hello"` 没被改动。

---

## 二、相等性比较：`equals` vs `==`

```java
s.equals(t)                        // 检测两个字符串内容是否相等
"Hello".equalsIgnoreCase("hello")  // 忽略大小写比较
```

**不要用 `==` 比较两个字符串内容！**

- `==` 只能确定两个字符串是否**存放在同一个位置**（即是否为同一个对象）
- 内容相同但位置不同的两个字符串，`==` 会返回 `false`

---

## 三、空串与 null

| 概念 | 含义 | 检查方式 |
|------|------|----------|
| 空串 | 长度为 0 的字符串，真实存在的对象 | `str.length() == 0` 或 `str.equals("")` |
| null | 变量没有指向任何对象 | `str == null` |

**注意顺序**：先判 null 再判空串，否则对 null 调用 `str.length()` 会抛 `NullPointerException`：

```java
if (str != null && str.length() == 0) { ... }
```

---

## 四、码点（code point）与代码单元（code unit）

`String` 内部以 **UTF-16 代码单元（char）** 存储，**不是**直接的 Unicode 码点：

- 一个 `char` 是一个 UTF-16 代码单元（2 字节）
- BMP 内常用字符：一个代码单元
- 增补字符（部分 emoji、生僻字）：需要**两个**代码单元（代理对）
- `length()` 返回的是代码单元个数，**不一定**等于实际字符数（码点个数）

```java
// 实际字符数（码点个数）
int cpCount = greeting.codePointCount(0, greeting.length());

// charAt 返回的是代码单元，不是码点
char first = greeting.charAt(0);   // 'H'

// 找第 i 个 Unicode 码点（跳过代理对）
int index = greeting.offsetByCodePoints(0, i);
int cp    = greeting.codePointAt(index);
```

## 五、String 常用 API

| 方法 | 作用 |
|------|------|
| `length()` | 长度（**代码单元数**） |
| `charAt(int)` | 返回指定位置的代码单元 |
| `codePointAt(int)` | 返回指定位置的码点 |
| `codePointCount(int, int)` | 区间内码点个数 |
| `offsetByCodePoints(int, int)` | 从 start 偏移 count 个码点后的索引 |
| `substring(int, int)` | 子串 [begin, end) |
| `equals(Object)` / `equalsIgnoreCase(String)` | 内容比较 |
| `compareTo(String)` | 按字典序比较，返回差值 |
| `startsWith(String)` / `endsWith(String)` | 前缀 / 后缀判断 |
| `indexOf(String)` / `lastIndexOf(String)` | 查找子串位置（找不到返回 -1） |
| `concat(String)` | 拼接（等价于 `+`） |
| `replace(CharSequence, CharSequence)` | 替换所有匹配 |
| `toUpperCase()` / `toLowerCase()` | 大小写转换 |
| `trim()` / `strip()` | 去首尾空白（`strip` Java 11+，支持 Unicode 空白） |
| `repeat(int)` | 重复 n 次（Java 11+） |
| `split(String regex)` | 按正则拆分成 `String[]` |
| `String.join(sep, a, b, ...)` | 静态方法，用分隔符连接 |
| `isEmpty()` / `isBlank()` | 长度为 0 / 只含空白（`isBlank` Java 11+） |
| `String.valueOf(x)` | 各类型转字符串 |

## 六、构建字符串：StringBuilder

字符串拼接用 `+`，**每次都构建新 String 对象，既耗时又浪费空间**（因为 String 不可变）。**频繁拼接请用 StringBuilder**。

```java
// 1. 构建空构建器
StringBuilder builder = new StringBuilder();

// 2. 需要时调用 append
builder.append(ch);   // 追加字符
builder.append(str);  // 追加字符串

// 3. 完成时调用 toString
String completedString = builder.toString();
```

**线程安全选择**：

- 单线程 → `StringBuilder`（快）
- 多线程共享同一个构建器 → `StringBuffer`（慢但线程安全）

## 七、读取输入：Scanner

```java
import java.util.Scanner;
import java.nio.file.Path;

// 读键盘输入
Scanner in = new Scanner(System.in);

// 读文件
Scanner in = new Scanner(Path.of("myfile.txt"), StandardCharsets.UTF_8);

// 常用方法
in.nextLine()    // 读一行
in.next()        // 读一个单词
in.nextInt()     // 读一个 int
in.nextDouble()  // 读一个 double

in.close();      // 用完释放资源
```

## 📌 易错点

1. **`==` 不能用于字符串内容比较**——只比是不是同一个对象。这是新手最常踩的坑。
2. **`null` 的字符串操作必崩**——先判 null。
3. **`length()` 是代码单元数**，不是字符数——处理 emoji / 生僻字要用 `codePointCount`。
4. **`+` 拼接在循环里是大坑**——`String s = ""; for (...) s += x;` 每次创建新对象，O(n²) 复杂度。**循环拼接必用 StringBuilder**。
5. **`String.valueOf(null)` 返回字符串 `"null"`**，不会抛 NPE——这往往是 bug 源头。
6. **Java 字符串字面量是 interned 的**——两个相同字面量 `==` 可能是 `true`，但这是**巧合**，不能用 `==` 替代 `equals`。

