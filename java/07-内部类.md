# 07 · 内部类

> 一句话概括：Java 内部类分四种，按「绑定外部实例的方式」区分。

---

## 一、成员内部类（non-static inner class）

```java
class Outer {
    class Inner { }
}
```

### 创建方式

**必须先有 Outer 实例**，再 `new` 一个 Inner：

```java
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();   // 不是 new Outer.Inner()！
```

### 特征

- 与外部类对象存在**强关联**（Inner 持有 Outer 实例的引用）
- 可以直接访问外部类的**实例成员**（包括 private）

```java
class Outer {
    private int x = 10;

    class Inner {
        void test() {
            System.out.println(x);   // 直接访问 Outer 的私有字段
        }
    }
}
```

### 显式引用外部对象

如果内部类想明确指出关联的外部对象，用 `Outer.this`：

```java
Outer outerRef = Outer.this;   // 当前 Inner 关联的那个 Outer 实例
```

---

## 二、静态嵌套类（static nested class）

```java
class Outer {
    static class Inner { }
}
```

### 创建方式

**不需要 Outer 实例**：

```java
Outer.Inner inner = new Outer.Inner();   // 不用先 new Outer()
```

### 特征

- **不绑定**某一个具体的 Outer 实例
- 只能直接访问 Outer 的**静态成员**，**不能直接**访问 Outer 的实例字段
- 实际上更接近「Outer 命名空间下的独立类」

---

## 三、局部内部类（local class）

定义在**方法或代码块内部**：

```java
void test() {
    class Inner {
        void hello() {
            System.out.println("hello");
        }
    }

    Inner inner = new Inner();
    inner.hello();
}
```

### 特征

- 作用域**只在对应的方法/代码块内**
- 可以访问外部成员，以及满足要求的局部变量
- 局部变量如果被内部类捕获，需要是 **final 或 effectively final**（没有重新赋值）

```java
void test() {
    final int x = 10;          // OK
    int y = 20;                // OK（未重新赋值，effectively final）
    // y = 30;                 // ❌ 一旦重新赋值，就不能被内部类捕获

    class Inner {
        void show() {
            System.out.println(x + y);   // OK
        }
    }
}
```

---

## 四、匿名内部类（anonymous class）

**没有名字**，直接创建：

```java
Runnable r = new Runnable() {
    @Override
    public void run() {
        System.out.println("run");
    }
};
```

### 常见用途

- 临时继承一个类
- 临时实现一个接口
- 回调
- 老式事件处理

### 与 Lambda 的区别

> **Lambda 并不是「把匿名内部类换了一种写法」。**

| 维度 | 匿名内部类 | Lambda |
|------|-----------|--------|
| 目标 | 任意类 / 任意接口（单方法也行） | **必须是函数式接口**（只有一个抽象方法） |
| `this` 指向 | 匿名类自身 | **外部类实例** |
| 编译产物 | 单独的 `.class` 文件 | `invokedynamic` 指令，更轻 |
| 可读性 | 啰嗦 | 简洁 |

---

## 五、四种内部类速查对比

| 类型 | 声明位置 | 关联外部实例？ | 创建语法 |
|------|----------|--------------|----------|
| 成员内部类 | 类内部、方法外 | ✅ 强关联 | `outer.new Inner()` |
| 静态嵌套类 | 类内部、方法外 | ❌ 不关联 | `new Outer.Inner()` |
| 局部内部类 | 方法/代码块内 | ✅ | `new Inner()` |
| 匿名内部类 | 表达式位置 | ✅ | `new 父类/接口() { ... }` |

---

## 📌 易错点

1. **成员内部类不能脱离外部实例创建**——`new Outer.Inner()` 是**错的**，必须先有 Outer。
2. **静态嵌套类不能直接访问外部类的实例字段**——只能访问静态成员。
3. **局部内部类捕获的局部变量必须是 final / effectively final**——Java 8 之后没显式 final 也行，但**不能重新赋值**。
4. **匿名内部类的 `this` 指匿名类自身**，而 Lambda 的 `this` 指**外部类**——这个差异在事件回调里很常见。
5. **内部类会持有外部类引用**——长期持有会阻止外部类被 GC，可能内存泄漏。静态嵌套类没有这个问题。
6. **Lambda 只能用于函数式接口**——`new Comparator() {...}` 在 Java 8+ 通常写成 `(a,b) -> ...`。

---

## 🧠 速记口诀

```
成员内部：跟 outer 走，outer.new
静态嵌套：跟类走，new Outer.Inner
局部内部：在方法里，捕获要 final
匿名内部：直接 new 类/接口+花括号
匿名内部与 Lambda：this 指向不同，Lambda 仅限函数式接口
```
