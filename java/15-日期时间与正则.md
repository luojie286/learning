# 15 · 日期时间与正则

> 一句话概括：日期用 **`java.time`**（新的，别碰 `Date`/`Calendar`），字符串匹配用**正则**（Java 里反斜杠要写两个）。

这两个都属于「**知道怎么用、用到再查**」的工具型内容，不必死背 API。

---

## 一、日期时间：`java.time`

现代 Java 日期时间 API 全在 **`java.time`** 包下。

| 类 | 职责 |
|---|---|
| `LocalDate` | 日期（年月日） |
| `LocalTime` | 时间（时分秒） |
| `LocalDateTime` | 日期 + 时间 |
| `Instant` | 时间戳（机器时间轴上的一个点） |
| `Duration` | 时间量（秒/纳秒级，用于时间差） |
| `Period` | 日期间隔（年月日级） |
| `DateTimeFormatter` | 格式化 / 解析 |

### 典型用途

用户注册时间、订单创建时间、会员过期时间、定时任务、日志时间、数据库时间字段、时间比较与计算。

### 常用写法

```java
LocalDate today = LocalDate.now();
LocalDate sevenDaysLater = today.plusDays(7);   // 计算

today.isAfter(expireDate);    // 比较
today.isBefore(expireDate);

DateTimeFormatter formatter =
        DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String s = today.format(formatter);             // 格式化
LocalDate parsed = LocalDate.parse("2026-09-14");   // 解析
```

### 掌握要求

- 记住映射关系即可：`LocalDate` 日期 / `LocalTime` 时间 / `LocalDateTime` 两者 / `DateTimeFormatter` 格式化
- 复杂 API 用到时查文档
- **新代码一律优先 `java.time`**，旧的 `Date` / `Calendar` 不必重点学

## 二、正则表达式

正则用来描述**字符串的匹配规则**。入口 API：

```java
"123".matches("\\d{3}");              // 是否整体匹配：恰好 3 个数字
"abc123def456".replaceAll("\\d+", "#");  // 搜索替换 → "abc#def#"
```

### 2.1 常用规则速查

```text
.        任意字符
\d       数字            \w   字母/数字/下划线      \s   空白字符
\d+ 或 \D 可以加反义：\D 表示「非数字」

*        0 次或多次
+        1 次或多次
?        0 次或 1 次

{3}      恰好 3 次
{2,5}    2 ~ 5 次

[abc]    a、b、c 中任意一个
[a-z]    小写字母
^  $     字符串开头 / 结尾
```

### 2.2 Java 里的转义：反斜杠要写两个

Java 字符串本身用 `\` 转义，所以正则里的 `\d` 必须写成 `\\d`：

```java
"\\d"     // ✅ 正则收到的是 \d
"\d"      // ❌ 编译期就是非法转义
```

### 2.3 分组

```regex
(\d{4})-(\d{2})-(\d{2})
```

匹配 `2026-09-14` 时，括号把规则分成三组并**捕获**结果：`2026` / `09` / `14`。

`()` 的作用是「把一部分规则当作一个整体」，同时可用于反向引用和提取。

### 2.4 贪婪与非贪婪

```regex
.*     尽可能多匹配  → 贪婪（默认）
.*?    尽可能少匹配  → 非贪婪
```

知道区别即可，遇到具体场景再推敲。

### 掌握要求

重点掌握：基本匹配规则、Java 的 `\\` 转义、`matches()`、`replaceAll()`、分组概念。

**不需要背**复杂的邮箱 / URL 正则——那些用到时再查。

### 值得手写（只有 3 个小例子）

1. 判断字符串是否全为数字
2. 匹配简单日期格式
3. 用 `replaceAll()` 把连续数字替换掉

---

## 📌 易错点

1. **正则里的 `\d` 在 Java 字符串中必须写 `\\d`**——少一个反斜杠直接编译报错。
2. **`matches()` 是整体匹配，不是查找**——`"abc123".matches("\\d+")` 是 `false`；要找子串请用 `Pattern` + `Matcher.find()`。
3. **`replaceAll()` 的第一个参数是正则**，不是普通字符串——想替换 `.` 这种元字符必须写 `"\\."`。
4. **`yyyy` 与 `YYYY` 含义不同**——`YYYY` 是「周历年」，跨年那几天会出错，日常写法统一用 `yyyy-MM-dd`。
5. **`LocalDate` / `LocalDateTime` 是不可变对象**——`today.plusDays(7)` 返回新对象，**必须接收返回值**，`today` 本身不会变。
6. **别再用 `Date` / `SimpleDateFormat`**——`SimpleDateFormat` 不线程安全，新代码一律 `java.time`。
