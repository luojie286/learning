## 二、核心口诀速记卡

把整份笔记浓缩成 23 句话，用来快速回忆。

**基础篇（01–10）**

1. **跨平台**：`javac 编译 .class → 各平台 JVM 解释执行`
2. **基本类型**：`byte1 short2 int4 long8 / float4 double8 / char2 / boolean 看实现`
3. **字面量默认类型**：`整数 → int`，`小数 → double`，`long 加 L`，`float 加 F`
4. **字符串比较**：`内容用 equals`，`== 只看是不是同一个对象`
5. **字段 vs 方法多态**：**字段看引用类型，方法看运行时对象**（这是最重要的一条）
6. **重写权限**：可以扩大（private → public），不能缩小（public → private）
7. **重写返回值**：基本类型必须相同；引用类型可以协变（返回更具体的子类）
8. **抽象类 vs 接口**：抽象类强调「是什么 (is-a)」，接口强调「能做什么 (can-do)」
9. **接口字段**：默认 `public static final`，是常量不是实例字段
10. **异常分类**：必须捕获的叫 Checked Exception；Error / RuntimeException 不用捕获

**进阶篇（11–18）**

11. **集合选型**：`List 有序可重复 / Set 去重 / Map 键值对 / Queue 先进先出`；`Map` 不属于 `Collection`
12. **集合底层**：只有三样——数组（ArrayList）、链表（LinkedList）、红黑树（TreeMap/TreeSet）；`equals` 重写必配 `hashCode`
13. **泛型**：默认不变，`A extends B` 推不出 `Generic<A> extends Generic<B>`；**PECS**——生产者 extends、消费者 super
14. **IO**：文本用字符流、二进制用字节流；`read()` 完返回 `-1`、`readLine()` 完返回 `null`；打开必用 try-with-resources
15. **并发**：进程管资源、线程管执行；`count++` 是读-改-写三步；互斥的关键是**竞争同一把锁**；`interrupt()` 是请求不是强杀
16. **安全**：编码 ≠ 加密、哈希 ≠ 加密；`AES` 对称、`RSA/ECC` 非对称；签名**私钥签、公钥验**；密码存储用 bcrypt + salt
17. **JUC**：CAS 乐观重试、Atomic 封装 CAS；`put/take` 满空会等、`offer/poll` 立刻返回；线程池四步**核心 → 队列 → 临时线程 → 拒绝**
18. **网络**：IP 是楼、端口是房间；TCP 连了再传可靠有序、UDP 拿起就发尽力而为；`accept()` 阻塞等连接、返回的 `Socket` 才是连接本身

**并发与 JVM 深入篇（19–23）**

19. **JMM**：管可见性/原子性/有序性；**JMM 是规则，不是缓存**（JVM 内存区域才管数据放哪）；happens-before 六条 + 传递性
20. **volatile**：可见性 + 有序性，**不互斥、不保复合原子**；`count++` 加了照样丢更新；一个线程写、其他线程读才用它
21. **异步**：`submit` 不阻塞、`get` 才阻塞；`thenApply` 加工 / `thenAccept` 消费 / `thenRun` 只管完成；异步 = 把等待推迟到需要结果时
22. **类加载**：加载 → 验证 → 准备 → 解析 → 初始化；**准备给零值、初始化赋真值**（`static final` 常量例外）；父先于子，`static{}` 只一次
23. **JVM 执行**：栈式字节码（栈顶隐式取数）vs 寄存器式（显式编号）；栈帧 = 局部变量表 + 操作数栈 + 动态链接；栈帧线程私有，局部变量不共享
