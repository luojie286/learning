## 二、核心口诀速记卡

把整份 Java 基础浓缩成 10 句话，用来快速回忆：

1. **跨平台**：`javac 编译 .class → 各平台 JVM 解释执行`
2. **基本类型**：`byte1 short2 int4 long8 / float4 double8 / char2 / boolean 看实现`
3. **字面量默认类型**：`整数 → int`，`小数 → double`，`long 加 L`，`float 加 F`
4. **字符串比较**：`内容用 equals`，`== 只看是不是同一个对象`
5. **字段 vs 方法多态**：**字段看引用类型，方法看运行时对象**（这是最重要的一条）
6. **重写权限**：可以扩大（private → public），不能缩小（public → private）
7. **重写返回值**：基本类型必须相同；引用类型可以协变（返回更具体的子类）
8. **抽象类 vs 接口**：抽象类强调「是什么 (is-a)」，接口强调「能做什么 (can-do)」
9. **接口字段**：默认 `public static final`，是常量不是实例字段
10. **异常分类**：必须捕获的叫 Checked Exception；Error / RuntimeException 不用捕获
