# 02 · 包与导入

> 一句话概括：Java 的包就是目录，import 只是名字缩短器。

---

## 一、包（package）与源根目录

**源根目录（source root）** 就是包文件夹的「上层」，通常就是项目里的 `src`。

```
src                    ← 源根目录
└── blackjack          ← 包 blackjack
    ├── Card.java
    ├── Deck.java
    └── Main.java
```

### 规则

- **每个包 = 源根下面的一个文件夹**，包文件夹里直接放 `.java` 文件
- 源文件第一行用 `package blackjack;` 声明所属包，**且必须与目录结构一致**
- 编译后的 `.class` 也要放在对应的包目录下，JVM 靠这个结构定位类

---

## 二、import 的两种用法

### 2.1 普通 import（按需或通配）

```java
import java.util.Scanner;       // 导入单个类
import java.nio.file.Path;      // 多个 import 可以并列
import java.util.*;             // 通配：导入 java.util 下所有类（不影响性能，编译期）
```

### 2.2 静态 import（导入类的静态成员）

```java
import static 包名.类名.静态成员名;   // 导入指定的静态成员
import static 包名.类名.*;           // 导入所有静态成员
```

静态导入后，可以直接写静态成员名，不用再加类名前缀：

```java
import static java.lang.Math.*;

double x = sqrt(PI);   // 不必写 Math.sqrt(Math.PI)
```

## 三、Java 文件结构

```java
package com.example.demo;      // ① package（必须是第一条非注释语句）

import java.util.List;         // ② import

public class User {            // ③ 类/接口/枚举/record
    private String name;       // ④ 字段
    public User(String name) { this.name = name; }   // ⑤ 构造方法
    public void hello() { System.out.println(name); } // ⑥ 方法
}
```

顺序：`package → import → 类声明 → 字段 → 构造方法 → 方法`。

### 一个 `.java` 文件里能有几个类？

```java
public class Main { }   // 最多一个 public 顶级类
class User { }          // 非 public 顶级类可以有多个
class Student { }
```

> **一个 `.java` 最多一个 `public` 顶级类**，且若有 `public class Main`，文件名必须是 `Main.java`。

## 四、import 的四个细节

| 场景 | 要不要 import | 说明 |
|---|---|---|
| 同一个 package 内的类 | **通常不用** | 同包可直接引用 |
| `java.lang` 下的类（`String`、`Math`…） | **不用** | JVM 自动导入 |
| 其他包的类 | 要 | 或写全限定名 `java.util.List<String> list;` |
| 自己写的不同包 | 要 | 条件是「包结构正确 + 目标类在 classpath 内」 |

自己写的项目里跨包引用，**关键不是两个包必须在同一目录**，而是：

```text
包结构（package 与目录对应） + 目标类位于可访问的源码路径/classpath 中
```

```java
package com.example.app;
import com.example.util.UserUtil;   // 不同包，正常 import

public class Main {
    public static void main(String[] args) { UserUtil.test(); }
}
```

## 📌 易错点

1. **`package` 声明必须严格匹配目录结构**——`package a.b;` 必须放在 `a/b/` 目录下，否则编译报错。
2. **`package` 必须是文件第一条非注释语句**，且一个 `.java` 只能有一个 `package`。
3. **静态导入会牺牲可读性**——滥用 `import static java.lang.Math.*;` 后，别人读你的代码看不出 `sqrt` 来自哪里。**局部小范围内用，全局慎用**。
4. **通配 import `.*` 不会拖慢运行**，编译期就解析完了；但 IDE 的智能提示会变得不精确。
5. **`java.lang` 不需要 import**，JVM 默认导入。
6. **一个文件写两个 `public` 类** ✗——最多一个，且 public 类名必须与文件名一致。
7. **以为「两个包必须在同一目录才能互相 import」** ✗——只要包结构正确且在 classpath 内即可。
