# 2026-09-01 Java 学习笔记

## 一、Java 的跨平台原理（一次编译，到处运行）

Java 的平台兼容性得益于 **javac（编译器）** 和 **JVM（Java 虚拟机）** 的分工：

```
Hello.java ──javac 编译──> Hello.class（字节码）──> 任意平台 JVM 识别并执行
```

- javac 把 `.java` 源码编译成 `.class` 字节码文件；
- 字节码不面向任何具体操作系统，只面向 JVM；
- 各平台（Windows / Linux / macOS）各自实现 JVM，都能识别同一份 `.class` 文件。

所以跨平台的关键是：**编译一次，处处运行**——前提是那个平台装了对应版本的 JVM。

## 二、注释

| 类型 | 语法 | 说明 |
|------|------|------|
| 单行注释 | `// ...` | 到行尾为止 |
| 多行（块）注释 | `/* ... */` | **不可嵌套**（详见 09-02 笔记） |
| 文档注释 | `/** ... */` | 供 javadoc 工具生成 API 文档 |

编辑器快捷键：

- VS Code：`Shift + Alt + A` 切换块注释，`Ctrl + /` 切换单行注释
- IDEA：`Ctrl + /` 单行，`Ctrl + Shift + /` 块注释

## 三、基本数据类型占用的字节数

| 类型 | 字节数 | 位数 | 取值范围 | 备注 |
|------|--------|------|----------|------|
| `byte` | 1 | 8 | -128 ~ 127 | |
| `short` | 2 | 16 | -32768 ~ 32767 | |
| `int` | **4** | 32 | 约 ±21 亿（-2³¹ ~ 2³¹-1） | 整数默认类型 |
| `long` | 8 | 64 | 约 ±9.2×10¹⁸ | 字面量加 `L`，如 `100L` |
| `float` | 4 | 32 | | 字面量加 `F`，如 `3.14F` |
| `double` | 8 | 64 | | 浮点数默认类型 |
| `char` | 2 | 16 | 0 ~ 65535 | UTF-16 代码单元 |
| `boolean` | — | — | `true` / `false` | 规范未定义具体大小 |

记忆要点：

- **int 4 字节，short 2 字节**；
- 整型字面量默认 `int`，浮点字面量默认 `double`；
- `long` → `float` 赋值给 `int` 等小类型需要强制转换，可能丢失精度。
