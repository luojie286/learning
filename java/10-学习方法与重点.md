# 10 · 学习方法与重点

> 一句话概括：概念驱动 + 最小例子验证 + 工程实践，别再逐行抄教材。

---

## 一、不要逐行敲教材

> **学习 Java 时，没有必要把教材里的每一行代码全部手敲一遍。**

尤其你已经有 C++ / 数据结构与算法基础，再把：

```java
System.out.println(...)
String.valueOf(...)
LocalDate.now()
```

之类的简单 API 每个例子都重新敲一遍，**收益非常低**。

---

## 二、推荐的学习循环

```
理解概念
   ↓
自己敲一个最小例子
   ↓
运行验证
   ↓
稍微修改代码
   ↓
确认理解
   ↓
继续下一个知识点
```

**而不是**：

```
教材第一行
  ↓
照抄
  ↓
教材第二行
  ↓
照抄
  ↓
感觉「学完了」
```

---

## 三、哪些东西值得亲手写

下面这些内容**建议一定要亲自敲**：

### 面向对象

- class / object
- extends / implements
- override / overload
- this / super
- 多态
- 抽象类 / 接口

### Java 核心

- 异常
- 泛型
- 集合
- Lambda
- Stream
- IO
- 多线程
- 反射

这些不仅是语法问题，而是需要**手感**——亲手写一遍才能形成代码直觉。

---

## 四、哪些东西不用刻意背

```java
String.valueOf(2)
LocalDate.now()
System.out.println()
```

这种 API 没必要追求「闭眼能写出来」。

> 真正重要的：**知道它能干什么 + 知道大概怎么用 + 会查 API**。

比死记语法重要得多。

---

## 五、学习 Java 的最终目标

不要把目标定成：

> ❌ 「把 Java 所有语法全部背下来。」

更好的目标是：

> ✅ 「**看到 Java 代码能快速理解，遇到常见场景能自己写出来，不熟悉的 API 能快速查到并使用。**」

---

## 六、当前阶段适合的方式

> **「概念驱动 + 小代码验证 + 工程实践」**

而不是传统的：

> ❌ 「从头到尾把 Java 语法书全部敲一遍」

简单语法可以快速过，把时间留给**真正用得到的核心能力**。

## 八、今天最值得记住的几个结论

1. **字段没有多态，方法有多态**
   ```
   字段 → 看引用类型
   方法 → 看运行时对象
   ```

2. **子类重写方法时不能降低访问权限**
   ```
   可以扩大，不能缩小
   ```

3. **重写的返回值**
   ```
   基本类型 → 必须相同
   引用类型 → 可以协变
   ```

4. **抽象类 vs 接口**
   ```
   抽象类 → 「是什么」(is-a)
   接口   → 「能做什么」(can-do)
   ```

5. **接口字段默认常量**
   ```
   public static final
   ```

6. **内部类主要四类**
   ```
   成员内部类 / 静态嵌套类 / 局部内部类 / 匿名内部类
   ```

7. **学 Java 不需要逐行抄代码**
   ```
   理解 → 动手验证 → 变式练习 → 应用
   而不是：抄代码 → 机械记忆
   ```

## 📌 易错点

1. **不要陷入「看完教材 = 学完 Java」的错觉**——必须上手写。
2. **不要死记 API**——养成查文档的习惯。
3. **不要按教材顺序学**——按工程实用度排优先级，跳着学。
4. **不要跳过基础**——集合 / 异常 / 泛型 / IO 这四块没学好，后面的 Spring 就是空中楼阁。

---

```
概念驱动，小例验证，变式练习，应用

OOP + 集合 + IO + 异常 + 泛型 + Lambda + 多线程 + JVM
这八块没学透，别急着上 Spring
```
