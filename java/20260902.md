# 2026-09-02 Java 学习笔记

## 一、包（package）与源根目录

**根（源根目录，source root）** 就是包文件夹的"上层"，在当前项目里就是 `src`。

规则：**每个包 = 根下面的一个文件夹，包文件夹里直接放 `.java` 文件。**

```
src                    ← 根（源根目录）
└── blackjack          ← 包 blackjack
    ├── Card.java
    ├── Deck.java
    └── Main.java
```

- 源文件第一行用 `package blackjack;` 声明所属包，且必须与目录结构一致；
- 编译后的 `.class` 也要放在对应的包目录下，JVM 靠这个结构定位类。

## 二、块注释不可嵌套

在 Java 中，`/* */` 注释**不能嵌套**。不能简单地把一段代码用 `/*` 和 `*/` 括起来注释掉，因为这段代码本身可能已经包含一个 `*/`，会导致注释提前结束、后面的代码暴露出来。

想注释大段代码时，更稳妥的做法是用 IDE 的行注释快捷键（`Ctrl + /`）逐行注释。

## 三、静态导入

```java
import static 包名.类名.静态成员名;   // 导入指定的静态成员
import static 包名.类名.*;           // 导入所有静态成员
```

静态导入后，可以直接写静态成员名，不用再加类名前缀：

```java
import static java.lang.Math.*;

double x = sqrt(PI);   // 而不必写 Math.sqrt(Math.PI)
```

注意可读性代价：滥用静态导入会让人看不出某个方法来自哪个类。

## 四、switch 表达式（Java 14+）

需要在两个以上的值中做出选择时，可以使用 switch 表达式（Java 14 正式引入）：

```java
String seasonName = switch (seasonCode) {
    case 0 -> "Spring";
    case 1 -> "Summer";
    case 2 -> "Fall";
    case 3 -> "Winter";
    default -> "???";
};
```

- 使用 `->` 箭头语法，**没有 fall-through**，不需要 `break`；
- switch 表达式必须**穷举所有可能**（或提供 `default`），有返回值，可以直接赋给变量；
- 多个值合并：`case 1, 2, 3 -> "Q1";`

## 五、字符串（String）

### 5.1 不可变性

字符串本身不可以修改，但是可以**改变变量的指向**：

```java
String greeting = "Hello";
greeting = greeting.substring(0, 3) + "p!";   // "Help!"
```

本质是：`substring` + 拼接在新的内存空间开辟了一个新的 String 对象，然后让 `greeting` 改为指向它。原来的 `"Hello"` 没有被改动。

### 5.2 相等性比较：equals，而不是 ==

```java
s.equals(t)                        // 检测两个字符串内容是否相等
"Hello".equalsIgnoreCase("hello")  // 忽略大小写比较
```

**不要用 `==` 运算符检测两个字符串是否相等！** `==` 只能确定两个字符串是否存放在同一个位置上（是否为同一个对象）。内容相同但位置不同的两个字符串，`==` 会返回 `false`。

### 5.3 空串与 null

- **空串**：长度为 0 的字符串，是一个真实存在的对象。检查方式：

```java
if (str.length() == 0)
// 或
if (str.equals(""))
```

- **null**：变量没有指向任何对象。检查方式：

```java
if (str == null)
```

注意顺序：先判 null 再判空串，否则对 null 调用 `str.length()` 会抛 `NullPointerException`：

```java
if (str != null && str.length() == 0) { ... }
```

### 5.4 码点（code point）与代码单元（code unit）

`String` 内部以 **UTF-16 代码单元（char）** 存储，而不是直接的 Unicode 码点：

- 一个 `char` 是一个 UTF-16 代码单元（2 字节）；
- 大部分常用字符（BMP 内）一个代码单元搞定，但增补字符（如部分 emoji、生僻字）需要**两个**代码单元（代理对）；
- 所以 `length()` 返回的是代码单元个数，不一定是实际字符（码点）个数。

要想得到实际长度（即码点个数）：

```java
int cpCount = greeting.codePointCount(0, greeting.length());
```

`charAt(n)` 返回位置 n 的**代码单元**，n 介于 `0 ~ length()-1` 之间：

```java
char first = greeting.charAt(0);   // 'H'
char last  = greeting.charAt(4);   // 'o'
// 注意：以 char（UTF-16 代码单元）为单位，不是 Unicode 码点
```

找第 i 个 Unicode 码点（跳过代理对）：

```java
int index = greeting.offsetByCodePoints(0, i);
int cp    = greeting.codePointAt(index);
```

### 5.5 String 常用 API

| 方法 | 作用 |
|------|------|
| `length()` | 长度（代码单元数） |
| `charAt(int index)` | 返回指定位置的代码单元 |
| `codePointAt(int index)` | 返回指定位置的码点 |
| `codePointCount(int start, int end)` | 区间内码点个数 |
| `offsetByCodePoints(int start, int count)` | 从 start 偏移 count 个码点后的索引 |
| `substring(int begin, int end)` | 子串 [begin, end) |
| `equals(Object o)` / `equalsIgnoreCase(String s)` | 内容比较 |
| `compareTo(String s)` | 按字典序比较，返回差值 |
| `startsWith(String p)` / `endsWith(String s)` | 前缀 / 后缀判断 |
| `indexOf(String s)` / `lastIndexOf(String s)` | 查找子串位置，找不到返回 -1 |
| `concat(String s)` | 拼接（等价于 `+`） |
| `replace(CharSequence a, CharSequence b)` | 替换所有匹配 |
| `toUpperCase()` / `toLowerCase()` | 大小写转换 |
| `trim()` / `strip()` | 去除首尾空白（strip 是 Java 11+，支持 Unicode 空白） |
| `repeat(int n)` | 重复 n 次（Java 11+） |
| `split(String regex)` | 按正则拆分成 String[] |
| `String.join(sep, a, b, ...)` | 静态方法，用分隔符连接 |
| `isEmpty()` / `isBlank()` | 长度为 0 / 只含空白（isBlank 是 Java 11+） |
| `String.valueOf(x)` | 各类型转字符串 |

## 六、构建字符串：StringBuilder

有时需要由许多较短的字符串构建字符串（例如来自按键或文件中的单词）。如果用 `+` 拼接的方式，效率会很低：**每次拼接都会构建一个新的 String 对象，既耗时又浪费空间**（因为 String 不可变）。使用 `StringBuilder` 类可以避免这个问题。

步骤：

```java
// 1. 构建一个空的字符串构建器
StringBuilder builder = new StringBuilder();

// 2. 每次需要添加一部分内容时，调用 append 方法
builder.append(ch);   // 追加单个字符
builder.append(str);  // 追加一个字符串

// 3. 构建完成时，调用 toString 方法，得到包含构建器中字符序列的 String 对象
String completedString = builder.toString();
```

单线程用 `StringBuilder`；多线程共享同一个构建器才需要 `StringBuffer`（线程安全但更慢）。

## 七、读取输入：Scanner

要想读取一个文件，需要构造一个 **Scanner** 对象：

```java
import java.util.Scanner;
import java.nio.file.Path;

Scanner in = new Scanner(Path.of("myfile.txt"), StandardCharsets.UTF_8);
```

- 读键盘输入：`Scanner in = new Scanner(System.in);`
- 常用方法：`nextLine()`（读一行）、`next()`（读一个单词）、`nextInt()`、`nextDouble()`
- 用完记得 `in.close();` 释放资源
