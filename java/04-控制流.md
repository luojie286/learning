# 04 · 控制流

> 一句话概括：switch 表达式代替传统 switch，块注释不能嵌套。

---

## 一、switch 表达式（Java 14+）

需要在两个以上的值中做选择时，可以使用 switch 表达式（Java 14 正式引入）。

```java
String seasonName = switch (seasonCode) {
    case 0 -> "Spring";
    case 1 -> "Summer";
    case 2 -> "Fall";
    case 3 -> "Winter";
    default -> "???";
};
```

### 与传统 switch 的区别

| 特性 | 传统 switch | switch 表达式 |
|------|------------|---------------|
| 语法 | `case x: ... break;` | `case x -> ...;` |
| fall-through | **默认会**（要靠 break 阻断） | **没有** fall-through |
| 是否有返回值 | 否（switch 是语句） | 是（可以直接赋给变量） |
| 穷尽要求 | 无 | **必须穷举所有可能或写 `default`** |

### 合并 case

```java
String quarter = switch (month) {
    case 1, 2, 3 -> "Q1";
    case 4, 5, 6 -> "Q2";
    case 7, 8, 9 -> "Q3";
    default       -> "Q4";
};
```

### yield 返回复杂值

当 case 分支需要多行语句才能算出结果，用 `yield` 返回：

```java
int days = switch (month) {
    case 1, 3, 5, 7, 8, 10, 12 -> 31;
    case 4, 6, 9, 11            -> 30;
    case 2                      -> {
        System.out.println("平年还是闰年？");
        yield 28;
    }
    default -> throw new IllegalArgumentException();
};
```

## 二、块注释不可嵌套

在 Java 中，`/* */` 注释**不能嵌套**：

```java
/*
   一段代码：
   int x = 1;
   /* int y = 2; */   ← 这里注释提前结束了！
   int z = 3;          ← 这行暴露出来，会被编译
*/
```

> 想注释大段代码时，**更稳妥的做法是用 IDE 的行注释快捷键（`Ctrl + /`）逐行注释**。

---

## 📌 易错点

1. **switch 表达式忘记写 `default`**：编译期就会报错「non-exhaustive switch」，必须补上。
2. **传统 switch 的 fall-through**：默认会贯穿所有 case，除非你写 `break`。**新手最常踩的坑**。
3. **switch 表达式和传统 switch 不能混用语法**：要么全部 `->`，要么全部 `: break`，否则编译错。
4. **块注释嵌套**：以为外面包一层 `/* */` 就把代码注释掉了，结果代码里只要出现 `*/` 就提前结束。
5. **`yield` 只能在 switch 表达式里用**，不能在传统 switch 里。

## 🧠 速记口诀

```
新 switch 用 -> ，没有 fall-through
必须穷举（或 default），可以直接赋值
要返回复杂值用 yield，多 case 用逗号合并
块注释不能嵌套，要注释大段用 Ctrl+/ 逐行
```
