# 11 · 集合框架

> 一句话概括：**List 有序可重复、Set 去重、Map 存键值对、Queue 先进先出**——底层翻来覆去只有数组、链表、红黑树三样东西。

---

## 一、整体体系

```text
        Iterable
            ↑
        Collection
    ┌───────┼───────┐
    ↓       ↓       ↓
   List    Set    Queue
```

**`Map` 不属于 `Collection`**——它存的是键值对，不是单个元素，属于另一条独立分支。

| 接口 | 特点 | 常用实现 |
|------|------|----------|
| `List` | 有序、可重复、有下标 | `ArrayList`、`LinkedList` |
| `Set` | 不可重复 | `HashSet`、`LinkedHashSet`、`TreeSet`、`EnumSet` |
| `Queue` | 先进先出 | `ArrayDeque`、`PriorityQueue` |
| `Deque` | 双端队列（可当栈用） | `ArrayDeque` |
| `Map` | key → value，key 不可重复 | `HashMap`、`LinkedHashMap`、`TreeMap`、`EnumMap` |

## 二、List：ArrayList 与 LinkedList

### 常用操作

| 操作 | 写法 |
|------|------|
| 添加 | `add(x)` / `add(i, x)`（指定下标要搬元素） |
| 获取 | `get(i)` |
| 修改 | `set(i, x)` |
| 删除 | `remove(i)` 按下标 / `remove(obj)` 按元素 |
| 查询 | `contains(x)`、`indexOf(x)`，都是 `O(n)` |
| 大小 | `size()`、`isEmpty()`、`clear()` |

遍历三种写法：增强 for、普通 for、`Iterator`。**遍历中要删除元素时只能用 `Iterator`**（见第七节）。

### 底层与复杂度

| | `ArrayList` | `LinkedList` |
|---|---|---|
| 底层 | 动态数组 | 双向链表 |
| 随机访问 | `O(1)` | `O(n)` |
| 尾部添加 | 均摊 `O(1)` | `O(1)` |
| 中间插入/删除 | `O(n)`（搬元素） | 定位 `O(n)`；已定位才是 `O(1)` |
| 内存 / 缓存友好度 | 紧凑、好 | 松散、差 |

- `ArrayList` 扩容约 **1.5 倍**：`newCapacity = old + (old >> 1)`（`>> 1` 即除以 2）
- 注意 `size` ≠ 数组容量
- **实际开发中绝大多数场景直接用 `ArrayList`**

> 「LinkedList 插入删除一定是 O(1)」是**不严谨**的说法：`remove(100)` 仍要先从头/尾走过去定位。

### `List.of()`

Java 9+ 的 `List.of("A", "B")` 返回**不可修改** List：能读不能改（`set/add/remove` 全部抛异常），且**不允许含 `null`**。
想要可修改版本：`new ArrayList<>(List.of("A", "B", "C"))`。

## 三、Map

### 3.1 常用 API

| 方法 | 说明 |
|------|------|
| `put(k, v)` | key 不存在则新增；已存在则覆盖并**返回旧值**（首次返回 `null`） |
| `get(k)` | key 不存在返回 `null` |
| `getOrDefault(k, def)` | 计数器写法：`cnt.put(x, cnt.getOrDefault(x, 0) + 1)`，等价 C++ 的 `mp[x]++` |
| `containsKey(k)` | 平均 `O(1)`，判断 key 是否真的存在 |
| `containsValue(v)` | 需要遍历，`O(n)` |
| `remove(k)` | 删除；`remove(k, v)` 仅在键值同时匹配时删除 |
| `size()` / `isEmpty()` / `clear()` | |

### 3.2 遍历

```java
for (String k : map.keySet()) { }                    // 只取 key，返回 Set<K>
for (Integer v : map.values()) { }                   // 只取 value，返回 Collection<V>
for (Map.Entry<String, Integer> e : map.entrySet()) { // 同时取，推荐
    e.getKey();
    e.getValue();
}
```

### 3.3 HashMap 底层结构

```text
数组 + 链表 + 红黑树        // 核心数组：Node[] table，每个位置叫一个「桶」bucket

table[0] → null
table[1] → Node → Node
table[4] → Node → Node → Node
```

`put()` 流程：

```text
key → hashCode() → HashMap 做 hash 扰动 → 算下标 → 定位桶
  → 桶为空：直接插入
  → 桶非空：处理冲突（链表/树）
```

下标核心是 `index = hash & (table.length - 1)`（因此容量保持 2 的幂，可位运算代替取模）。

**树化**：链表冲突过长时（`TREEIFY_THRESHOLD = 8`）考虑转红黑树，把最坏查找从 `O(n)` 降到 `O(log n)`；但若数组容量还小于 `MIN_TREEIFY_CAPACITY = 64`，**优先扩容而不是树化**。

**扩容**：默认初始容量 16、负载因子 0.75，阈值 `16 × 0.75 = 12`，超出即翻倍扩容（16 → 32 → 64）。

### 3.4 hashCode 与 equals 契约

- `hashCode()` 负责**定位桶**，`equals()` 负责**确认是不是同一个 key**
- `hashCode` 相同 ≠ 对象相同（存在哈希冲突）
- 但若 `a.equals(b) == true`，则**必须** `a.hashCode() == b.hashCode()`

所以自定义对象当 key 使用时，**必须同时重写这两个方法**：

```java
@Override
public boolean equals(Object o) {
    if (this == o) return true;                        // 同一引用
    if (o == null || getClass() != o.getClass()) return false;  // null / 类型不同

    Student other = (Student) o;
    return age == other.age && Objects.equals(name, other.name);
}

@Override
public int hashCode() {
    return Objects.hash(name, age);                    // 只放参与 equals 的字段
}
```

`equals` 需满足：自反、对称、传递、一致，且对 `null` 返回 `false`。

### 3.5 Map 的 null 与实现对照

`HashMap` 允许**一个 null key**、**多个 null value**，所以 `map.get(k) == null` **不能**证明 key 不存在——要严格判断请用 `containsKey()`。

| 实现 | 底层 / 特点 | 复杂度 |
|------|-------------|--------|
| `HashMap` | 数组 + 链表 + 红黑树 | 平均 `O(1)` |
| `LinkedHashMap` | HashMap + 双向链表，维护插入/访问顺序 | 平均 `O(1)` |
| `TreeMap` | 红黑树，key 自动排序 | `O(log n)` |
| `ConcurrentHashMap` | 并发哈希结构 | 面向多线程 |
| `EnumMap` | 枚举序号 + 数组，无哈希无冲突 | 极高效 |

## 四、Set

> 不允许重复元素；没有下标。

```text
Set
├── HashSet          去重（无序）
├── LinkedHashSet    去重 + 保持插入顺序
├── TreeSet          去重 + 自动排序（红黑树，O(log n)）
└── EnumSet          枚举专用，位向量思想，最高效
```

### 常用操作

```java
set.add(x);          // 返回 boolean：本来就是 false，说明重复没加进去
set.contains(x);     // HashSet 平均 O(1)
set.remove(x);
set.size();  set.isEmpty();  set.clear();
```

**HashSet 底层就是一个 HashMap**——元素当 key，value 统一放一个占位对象：

```java
map.put("Tom", PRESENT);   // 所以「元素不可重复」=「key 不可重复」
```

因为走的是 HashMap，**判断重复同样依赖 `hashCode` + `equals`**。

**TreeSet 判断重复靠 `compareTo()` / `Comparator`**：`compare(a, b) == 0` 即视为重复——这跟 HashSet 的机制不同。

TreeSet 常用有序操作：

```java
set.first();  set.last();
set.ceiling(x);   // ≥ x 的最小元素
set.floor(x);     // ≤ x 的最大元素
set.higher(x);    // > x
set.lower(x);     // < x
```

## 五、Queue / Deque / PriorityQueue

### 两套 API

| 操作 | 抛异常版 | 特殊值版（推荐） |
|------|----------|------------------|
| 入队 | `add()` | `offer()` |
| 查看队头 | `element()` | `peek()` |
| 出队 | `remove()` | `poll()` |

```java
Queue<Integer> queue = new ArrayDeque<>();
queue.offer(1);
queue.peek();     // 1，只看不删
int x = queue.poll();  // 删除并返回 1
```

**普通队列用 `ArrayDeque`**，不用 `LinkedList`：底层是可扩容循环数组，内存更紧凑、缓存局部性更好，`offer/poll/peek` 均摊 `O(1)`。

### Deque（双端队列）

```java
Deque<Integer> d = new ArrayDeque<>();
d.offerFirst(x);  d.offerLast(x);
d.peekFirst();    d.peekLast();
d.pollFirst();    d.pollLast();
```

### PriorityQueue

```java
PriorityQueue<Integer> pq = new PriorityQueue<>();                       // 默认小根堆
PriorityQueue<Integer> max = new PriorityQueue<>(Comparator.reverseOrder()); // 大根堆
```

> ⚠️ **这是与 C++ 最容易搞混的一处**：C++ `priority_queue<int>` 默认**大根堆**，Java `PriorityQueue` 默认**小根堆**。

复杂度：`offer` / `poll` 为 `O(log n)`，`peek` 为 `O(1)`。

## 六、Stack：为什么推荐用 Deque

```java
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);
stack.peek();   // 栈顶，不删
stack.pop();    // 删除并返回栈顶
```

`push()` = `addFirst()`、`pop()` = `removeFirst()`、`peek()` = `peekFirst()`——**头部即栈顶**。

老式 `Stack<E>` 依然存在，但**不推荐**，原因是它继承 `Vector`（`Object → Vector → Stack`）：

1. `Vector` 是较老的集合类，历史包袱重
2. 大部分方法带同步，单线程场景有额外开销
3. 官方现代 API 更推荐用 `Deque` 表达栈语义

> 注意：**「Stack 能删栈底」并不是不推荐它的核心理由**——Deque 作为双端队列本来就能操作两端，这是它合理的设计目标；把它当栈用，只用 `push/pop/peek` 即可。

`ArrayDeque` **不允许存 `null`**（`peek()` 用 `null` 表示空栈）。

算法场景：括号匹配、单调栈（通常存下标）、手写 DFS。

## 七、Iterator 与 fail-fast

`Iterator` 是遍历集合的统一「游标」，核心三方法：`hasNext()` / `next()` / `remove()`。

```java
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();   // 返回元素并前进
    if (s.equals("A")) it.remove();   // 删除最近一次 next() 返回的元素，安全
}
```

**为什么需要它**：各集合底层不同（数组 / 双向链表 / 哈希表 / 红黑树），`Iterator` 让外部代码不必关心底层实现。

**`Iterable` 与 `Iterator` 的分工**：

```text
Iterable  → 负责「产生」迭代器（Collection 继承它，核心方法 iterator()）
Iterator  → 负责「真正」遍历
```

增强 for 只是语法糖，本质就是上面那段 `while`——所以没有下标的 `HashSet` 也能 for-each。

### fail-fast（快速失败）

```java
for (String s : list) {
    if (s.equals("A")) list.remove(s);   // ❌ 可能抛 ConcurrentModificationException
}
```

原理：集合内部维护 `modCount`，迭代器创建时记录 `expectedModCount`；遍历中若发现两者不等，立即抛 `ConcurrentModificationException`。

> ⚠️ **这个异常名有误导性**——它跟多线程没有必然关系，**单线程也会抛**。它检测的是「迭代过程中集合结构被绕过迭代器修改了」。

用 `iterator.remove()` 时迭代器会同步自己的状态，所以能安全继续。

**LinkedList 为什么更适合用 Iterator 遍历**：`for (int i...) list.get(i)` 每取一个都要沿链表走，最坏 `O(n²)`；迭代器顺着节点走是 `O(n)`。

Map 本身不是 `Collection`，不能 `map.iterator()`，但可以 `map.keySet().iterator()` / `values().iterator()` / `entrySet().iterator()`。

`ListIterator` 是 List 专用增强版，额外支持 `hasPrevious()` / `previous()` 双向遍历，以及 `add()` / `set()`。

## 八、EnumMap 与 Properties

### EnumMap：key 是枚举就用它

```java
enum Status { TODO, DOING, DONE }

Map<Status, String> map = new EnumMap<>(Status.class);
map.put(Status.TODO, "未开始");
```

利用枚举的 `ordinal()`（固定序号）直接映射数组位置：

```text
values[0] → LOW 的值
values[1] → MEDIUM 的值
values[2] → HIGH 的值
```

**没有哈希计算、没有冲突、没有链表和红黑树**，因此比 `HashMap<Enum, V>` 高效得多。遍历顺序固定为枚举定义顺序。不允许 null key，允许 null value。

典型场景：`枚举状态 → 配置`、`枚举状态 → Handler`、`枚举权限 → 处理逻辑`。

### Properties：专门读配置

```java
Properties p = new Properties();
p.load(new FileInputStream("config.properties"));   // 读取
String user = p.getProperty("username");
String v = p.getProperty("xxx", "default");         // 带默认值
```

典型 `.properties` 文件：

```properties
username=root
password=123456
url=jdbc:mysql://localhost:3306/test
```

- **读出来永远是 `String`**：`age=18` 要 `Integer.parseInt(p.getProperty("age"))`
- 写文件用 `p.store(fos, "comment")`；遍历推荐 `p.stringPropertyNames()`
- 继承链：`Object → Dictionary → Hashtable → Properties`，虽然能 `put(123, 456)`，但**实际使用请坚持 String → String**，用 `setProperty/getProperty`
- 打包进 jar 后更推荐从 classpath 读：
  ```java
  getClass().getClassLoader().getResourceAsStream("config.properties");
  ```
- 中文编码：`load(InputStream)` 有 ISO-8859-1 兼容行为，要明确 UTF-8 请用 `load(new InputStreamReader(fis, StandardCharsets.UTF_8))`

| | `HashMap` | `Properties` |
|---|---|---|
| 主要用途 | 通用键值存储 | 配置文件 |
| key/value 类型 | 任意 | 通常 String/String |
| `load()` / `store()` | 无 | 有 |
| 线程安全 | 否 | 是（继承 Hashtable） |

## 九、与 C++ 对照总表

| 用途 | C++ | Java |
|------|-----|------|
| 哈希表 | `unordered_map<K,V>` | `HashMap<K,V>` |
| 有序表 | `map<K,V>` | `TreeMap<K,V>` |
| 计数 | `mp[key]++` | `map.put(k, map.getOrDefault(k, 0) + 1)` |
| 查询 key | `mp.count(key)` | `map.containsKey(key)` |
| 哈希集合 | `unordered_set<T>` | `HashSet<T>` |
| 有序集合 | `set<T>` | `TreeSet<T>` |
| 插入 / 查询 / 删除 | `insert` / `count` / `erase` | `add` / `contains` / `remove` |
| 队列 | `queue<int>`、`push/front/pop` | `Queue<Integer>`、`offer/peek/poll` |
| 双端队列 | `deque`、`push_front/pop_back` | `Deque`、`offerFirst/pollLast` |
| 优先队列 | `priority_queue<int>` = **大根堆** | `PriorityQueue<>` = **小根堆** |
| 栈 | `stack<int>`、`top()` | `Deque<Integer>`、`peek()` |
| 迭代器前进 | `*it` 取值，`++it` 前进（两步分开） | `it.next()` = **取值 + 前进**（一步完成） |

## 📌 易错点

1. **`List<Integer>.remove(1)` 删的是下标 1，不是值 1**——要删值 `1` 得写 `list.remove(Integer.valueOf(1))`。
2. **`map.get(k) == null` 不能判断 key 不存在**——HashMap 允许 null value，请用 `containsKey()`。
3. **遍历中直接 `list.remove(x)` 会抛 `ConcurrentModificationException`**——单线程也一样，必须用 `iterator.remove()`。
4. **Java `PriorityQueue` 默认小根堆，C++ 默认大根堆**——刷题时最容易翻车的一处。
5. **重写 `equals` 没重写 `hashCode`**，对象放进 `HashSet` / `HashMap` 会「找不到自己」。
6. **`List.of()` / `Arrays.asList()` 返回的不可修改**——想改要 `new ArrayList<>(...)`；`List.of` 还禁止 null。
7. **用 `Stack` 类不如用 `ArrayDeque`**——老类继承 `Vector`，带同步开销。
8. **`ArrayList` 的 `size` 不是数组容量**——扩容是 1.5 倍而不是 2 倍。
