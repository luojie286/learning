# 06 · 抽象类与接口

> 一句话概括：抽象类重在「是什么」，接口重在「能做什么」。

---

## 一、抽象类（abstract class）

抽象类本质上仍然是一个 **class**，可以拥有：

- 实例字段
- 构造方法
- 普通方法
- 抽象方法（没有方法体的方法）

```java
abstract class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    abstract void eat();   // 抽象方法：没有方法体，必须由子类实现

    void sleep() {
        System.out.println("sleep");
    }
}
```

### 抽象类表达什么

> **「它是什么」**——典型的 `is-a` 关系。

```java
class Dog extends Animal {        // Dog is an Animal
    public Dog(String name) {
        super(name);
    }

    @Override
    void eat() {
        System.out.println("Dog eats");
    }
}
```

---

## 二、接口（interface）

接口更偏向：

> **「它能做什么」**——典型的 `can-do` 关系。

```java
interface Flyable {
    void fly();   // 默认 public abstract
}

class Bird implements Flyable {
    @Override
    public void fly() {
        System.out.println("Bird flies");
    }
}
```

### 接口的杀手锏

> **一个类可以实现多个接口。**

```java
class Bird implements Flyable, Runnable {
}
```

而 Java 类只能直接 `extends 一个父类`（单继承）。

---

## 三、现代接口的能力

现代 Java 的接口已经不只是「纯抽象方法」了：

| 版本 | 新增能力 | 调用方式 |
|------|----------|----------|
| 最初 | 抽象方法、常量字段 | `impl.xxx()` |
| Java 8 | `default` 方法、`static` 方法 | `obj.test();` / `A.hello();` |
| Java 9 | `private` 方法 | 接口内部复用 |

### 示例

```java
interface A {
    default void test() {          // 默认方法
        System.out.println("default");
        helper();                   // 调用 private 复用方法
    }

    static void hello() {           // 静态方法
        System.out.println("hello");
    }

    private void helper() {         // private 方法（Java 9+）
        System.out.println("helper");
    }
}

// 调用
A obj = new A() {};
obj.test();    // 默认方法：实例调用
A.hello();    // 静态方法：接口名调用
```

### 因此现代接口可以拥有

- 抽象方法
- `default` 方法
- `static` 方法
- `private` 方法
- 常量字段

但接口和 class **依然不是同一种东西**——接口不能 `new`，不能有实例字段。

---

## 四、接口中的字段

接口中的字段默认具有：

```java
public static final
```

```java
interface Config {
    int MAX = 100;
}

// 等价于
public static final int MAX = 100;
```

所以是**常量**，不是每个对象独立拥有的实例字段。

---

## 五、抽象类 vs 接口 速查对比

| 维度 | 抽象类 | 接口 |
|------|--------|------|
| 关键字 | `abstract class` | `interface` |
| 表达 | **is-a**（是什么） | **can-do**（能做什么） |
| 实例字段 | ✅ 可以 | ❌ 只能常量（`public static final`） |
| 构造方法 | ✅ 可以 | ❌ 没有 |
| 普通方法 | ✅ 可以 | `default` / `static` / `private` |
| 抽象方法 | ✅ 可以 | ✅ 默认即抽象 |
| 继承数量 | 单继承（一个父类） | 多实现（多个接口） |
| 访问修饰 | 任意 | 默认 `public` |
| 何时用 | 共性骨架 / 模板方法 | 能力抽象 / 多重类型 |

---

## 📌 易错点

1. **抽象类不能 `new`**——但可以声明引用（多态）。
2. **抽象方法没有方法体**——连 `{}` 都不能写，必须 `;` 结尾。
3. **子类必须实现所有抽象方法**，否则子类也得是 `abstract`。
4. **接口字段默认是常量**——不能写 `private int x;`（会被自动改成 `public static final`）。
5. **接口的 `default` 方法可以被重写**，重写时可以去掉 `default`。
6. **`default` 方法可以解决多接口冲突**——但多个接口同名 default 时，子类必须显式重写。
7. **`default` 方法里可以调用 `private` 方法**（Java 9+ 设计的复用机制）。

---

## 🧠 速记口诀

```
抽象类：is-a，单继承，有字段有构造有实现
接口：can-do，多实现，字段默认常量无构造
现代接口：default 给实现，static 走接口名，private 自用
两者本质不同，别拿接口当 class 用
```
