## 一、跨平台原理（一次编译，到处运行）

```
Hello.java ──javac 编译──> Hello.class（字节码）──> 各平台 JVM 解释执行
```

- `javac` 把 `.java` 源码编译成 `.class` **字节码**（bytecode）
- 字节码不面向任何具体操作系统，**只面向 JVM**
- Windows / Linux / macOS 各自有自己的 JVM 实现，都能识别同一份 `.class`

**所以跨平台的关键是**：编译一次，处处运行——前提是目标平台装了**对应版本**的 JVM。

## 二、注释的三种写法

| 类型 | 语法 | 说明 |
|------|------|------|
| 单行注释 | `// ...` | 到行尾为止 |
| 多行（块）注释 | `/* ... */` | **不可嵌套**（详见 `04-控制流.md`） |
| 文档注释 | `/** ... */` | 供 `javadoc` 工具生成 API 文档 |

**编辑器快捷键**

| 编辑器 | 单行注释 | 块注释 |
|--------|---------|--------|
| VS Code | `Ctrl + /` | `Shift + Alt + A` |
| IDEA | `Ctrl + /` | `Ctrl + Shift + /` |

## 三、基本数据类型

### 3.1 占用的字节数

| 类型 | 字节 | 位数 | 取值范围 | 备注 |
|------|------|------|----------|------|
| `byte` | 1 | 8 | -128 ~ 127 | |
| `short` | 2 | 16 | -32768 ~ 32767 | |
| `int` | **4** | 32 | ±2¹⁵（≈ ±21 亿） | **整数默认类型** |
| `long` | 8 | 64 | ±9.2×10¹⁸ | 字面量加 `L`（如 `100L`） |
| `float` | 4 | 32 | — | 字面量加 `F`（如 `3.14F`） |
| `double` | 8 | 64 | — | **浮点数默认类型** |
| `char` | 2 | 16 | 0 ~ 65535 | UTF-16 代码单元 |
| `boolean` | — | — | `true` / `false` | JVM 规范未定义具体大小 |

### 3.2 字面量默认类型

```java
long x = 100;     // OK：100 是 int，能自动转 long
long y = 100L;    // 必须加 L，否则表达式超过 int 范围会报错
float z = 3.14;   // ❌ 编译错：3.14 默认是 double，不能自动转 float
float w = 3.14F;  // OK：加 F 显式说明是 float
```

---

## 📌 易错点

1. **`int 4 字节 / short 2 字节`** 是面试常考点，别和 `char 2 字节` 记混。
2. **`char` 是无符号 0~65535**，**不是** ASCII 范围；它存的是 UTF-16 代码单元。
3. **`long` 字面量建议大写 `L`** 而不是小写 `l`——小写 `l` 容易和数字 `1` 看错。
4. **`float` 字面量必须加 `F`**，否则编译错（`double → float` 不自动转）。
5. **`boolean` 不能和整型互转**——`if (a == 1)` 在 C 里能编，在 Java 里不行。
