# 动态规划与回溯：保留足以转移的信息

## 状态必须决定下一步

最长回文子串若只记录“以 i 结尾的最长回文长度”，下一字符可能需要较短后缀，信息并不足。例如 `abbb`，处理 abb 只记 bb，继续得到 bbb 却需要从更短的 b 扩展。

区间 DP 定义 pal[i][j] 为闭区间是否回文：两端相等且内部回文。长度 1/2 是边界，按区间长度递增，或 i 从后往前、j 从前往后，使内部先算。O(n²) 时间与空间。若只求最长串，枚举奇偶中心扩展 O(n²) 时间、O(1) 辅助空间；漏偶中心会漏掉 abba。

## 回溯是枚举选择，不是随意递归

电话号码字母组合每层选择当前数字的一种字母，做选择、递归、撤销。空输入按题意返回空列表；保存结果时复制路径，否则所有结果可能共享同一可变对象。最坏每位 4 个选择，长度 n 输出时间 O(n·4^n)，输出规模本身就很大。

括号生成维护 left、right 已使用数量。只允许 left<n 时加左括号，right<left 时加右括号，任意前缀都不能右多于左；此错误无法被后续修复，因而可剪枝。有效括号判定用栈验证嵌套类型，最后栈须为空，仅统计数量无法区分 `([)]`。

## 计数 DP：末尾连续 1 决定新增贡献

长度 N 的二进制串，所有全 1 连续子区间数等于每段长度 L 的 L(L+1)/2 之和。末尾已有 j 个连续 1，再加 1 新增 j+1 个子区间；加 0 不新增，并把 j 清零。

目标至少 K，可反算“小于 K”的坏串数，再从 2^N 中减去。状态 `(s,j)` 表示累计贡献 s<K 与末尾连续 1 长度 j；不需要完整历史串。

```python
def binary_at_least(n, k, mod):
    if n < 0 or k < 0 or mod <= 0: raise ValueError('参数无效')
    if k == 0: return pow(2, n, mod)
    dp = {(0, 0): 1}
    for _ in range(n):
        nxt = {}
        for (s, j), ways in dp.items():
            key = (s, 0)
            nxt[key] = (nxt.get(key, 0) + ways) % mod
            if s+j+1 < k:
                key = (s+j+1, j+1)
                nxt[key] = (nxt.get(key, 0) + ways) % mod
        dp = nxt
    return (pow(2, n, mod) - sum(dp.values())) % mod
```

N=2、K=2，00/01/10 的贡献分别 0/1/1，11 贡献 3，答案 1。稠密上界 O(NK²)、O(K²)，稀疏字典跳过不可达状态；由 j(j+1)/2<=s<K 可进一步限 j。大 K 不适用此状态界，不要只因为用了滚动数组就忽略转移总量。

## 开发对应与验证

生成所有权限组合是枚举问题；判断某种规则是否可行可能是 DP 或搜索；“最优一个”与“全部输出”不能混同。业务限制若只是偏好而非必然非法，不可当成剪枝条件删掉可能答案。

原题模数缺失，本文把 mod 作为显式参数，不声称 10^9+7 就是原题值。Python 二维数组用列表推导创建独立行；`[[0]*m]*n` 会共享行引用。用 N<=10 的完整 2^N 枚举核对 DP，可直接验证状态、边界 K=0 与阈值方向。
