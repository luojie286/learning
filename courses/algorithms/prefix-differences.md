# 前缀和与二阶差分：从公式检查边界

## 查询与修改的两面

定义 `pre[0]=0`，`pre[i+1]=pre[i]+a[i]`，半开区间 `[l,r)` 的和为 pre[r]-pre[l]。预处理 O(n)，静态区间求和 O(1)。若频繁改单点后立即查和，不能继续称每次 O(1)，需更新前缀或改用树状数组。

用数学式看，前缀把重复的累加工作提前完成，查询时相减即可消掉左侧共同部分：

$$
P_k=\sum_{i=0}^{k-1}a_i,\qquad \sum_{i=l}^{r-1}a_i=P_r-P_l
$$

一阶差分 `d[i]=a[i]-a[i-1]`，数组前补 0。对闭区间 `[l,r]` 加常数 s，只需 d[l]+=s，d[r+1]-=s，一次前缀和还原。它适合离线批量修改，最后一次恢复。

## 等差更新为什么要两次恢复

对零基 `[l,r]` 加 `s,s+step,...,e`，一次差分后为起点 s、中间 step、末尾之后 -e。再对这个分段数组差分，只剩四个突变：

```text
dd[l]   += s
dd[l+1] += step-s
dd[r+1] -= e+step
dd[r+2] += e
```

两次前缀和先恢复一阶差分，再恢复原数组增量；原稿两轮注释写反。n 个有效位置外至少留两个哨兵，恢复只取前 n 个结果。

```python
def apply_progressions(n, updates):
    dd = [0] * (n + 2)
    for l, r, s, step in updates:
        if not 0 <= l <= r < n: raise ValueError('区间越界')
        e = s + (r-l) * step
        dd[l] += s
        dd[l+1] += step-s
        dd[r+1] -= e+step
        dd[r+2] += e
    first = value = 0; out = []
    for i in range(n):
        first += dd[i]
        value += first
        out.append(value)
    return out
```

输入明确使用首项与步长，避免末项不能整除的问题。若输入首尾项且长度>1，整数任务必须检查 `(e-s)%(r-l)==0`；单点要求首末项一致。

## 修订：单点不能混用一阶表示

原稿 l==r 分支只改两个点 `+s,-s`，但随后仍做两次前缀和，会变成从该点开始一直 +s。反例 n=4，在位置 1 加 5，错误实现得到 `[0,5,5,5]`，正确应为 `[0,5,0,0]`。

统一公式令 step=0、l=r，重合项自然合并为 `dd[l]+=s, dd[l+1]-=2s, dd[l+2]+=s`。这才是二阶差分域中的单点脉冲，无需再用不匹配的一阶特判。

另一个推演：n=5，对 `[1,3]` 加 `[1,2,3]`，dd 的有效变化为 `[0,1,0,0,-4,3,0]`，前五位一阶恢复 `[0,1,1,1,-3]`，二次恢复 `[0,1,2,3,0]`。

## 开发场景与边界

批量为预约日历的区间增加占用数，可以先差分汇总再检查超额日期；逐步递增的活动额度可用二阶差分模拟。在线增删并即时查询则需其他结构，不能每次 O(n) 恢复后仍宣称整体 O(n+m)。固定宽度语言注意多次叠加和等差末项乘法溢出。

公式没有依赖某个缺失题目的异或输出要求，保留为独立可验证工具。建议用 n<=8 的随机输入与逐位置暴力更新交叉验证，覆盖单点、整段、零步长、负步长和相邻更新。
