# 📝 嵌入式基础概念笔记
## 什么是单片机
- 定义：一种集成了计算、控制、存储等功能的芯片。
- 地位：是“嵌入式控制的核心”，也是程序的执行者。

## 什么是 STM32
- 分类：属于 32位单片机 的一类。
- 内核：基于 ARM Cortex-M 内核。
- 特点：具备高性能、低功耗、丰富外设资源的特点。

## 什么是寄存器
- 定义：小块的临时存储区，用于存放运行中要使用的数据。
- 作用：在 STM32 中，用于快速存储当前正在使用的数据。

## 寄存器编程与 HAL 库编程的区别
| 编程方式 | 特点 | 优点 | 缺点 |
| ---- | ---- | ---- | ---- |
| 寄存器编程 | 直接操作底层硬件 | 控制精度高，性能最大化 | 开发复杂，难度大 |
| HAL 库编程 | 调用 HAL 库的接口来编程 | 开发更简单，移植性好 | 性能有所牺牲（相比寄存器） |
