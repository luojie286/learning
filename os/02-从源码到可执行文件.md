# 02 · 从源码到可执行文件

> 一句话概括：`gcc -o hello hello.c` 这一条命令的背后，是**预处理 → 编译 → 汇编 → 链接**四步。

> ⚠️ 说明：原始笔记（`20260905.md`）只有几行课堂速记，本文按标准流程补全展开，并在最后一节逐条还原原始记录。

## 一、四步流程与中间产物

```bash
linux> gcc -o hello hello.c
```

这一条命令内部其实跑了四个程序，产生三个中间文件：

```text
hello.c
  │ ① 预处理（cpp）
  ↓   展开 #include、#define，删注释
hello.i    （预处理后的完整源码）
  │ ② 编译（cc1）
  ↓   语法分析、代码优化，翻译成汇编
hello.s    （汇编代码，人类可读）
  │ ③ 汇编（as）
  ↓   逐条翻译成机器指令
hello.o    （目标文件，含机器码，但地址未定）
  │ ④ 链接（ld）
  ↓   与库函数合并、重定位地址
hello      （可执行文件）
```

| 步骤 | 工具 | 输入 → 输出 | 干什么 |
|---|---|---|---|
| 预处理 | `cpp` | `.c` → `.i` | 展开头文件与宏、条件编译、去注释 |
| 编译 | `cc1` | `.i` → `.s` | 语法/语义分析 + 优化，生成汇编 |
| 汇编 | `as` | `.s` → `.o` | 汇编翻译为机器码，生成目标文件 |
| 链接 | `ld` | `.o` + 库 → 可执行 | 合并目标文件与库，确定最终地址 |

想单步观察，可以手动执行：

```bash
gcc -E hello.c -o hello.i     # 只看预处理
gcc -S hello.c -o hello.s     # 只到汇编
gcc -c hello.c -o hello.o     # 只到目标文件
gcc -o hello hello.o          # 只链接
```

## 二、链接：与「库函数」合并

这是四步中最容易被忽略、也最容易报错的一步。

```text
hello.o 里调用了 printf，但 printf 的代码不在 hello.o 里
   ↓ 链接器去 C 标准库中查找 printf 的实现
   ↓ 把函数代码合并进来，并修正所有地址
   ↓ 得到完整的可执行文件
```

- **静态库**（`.a`）：库代码直接复制进可执行文件，体积大、运行时不依赖库
- **动态库**（`.so`）：只记录引用，运行时由动态链接器加载

> 这就是「**和 C 函数进行链接**」的含义——你的代码只负责「调用 `printf`」，`printf` 的实现来自标准库。

## 三、链接阶段的常见错误

```text
undefined reference to `xxx'
```

含义：**符号找不到**（函数声明了、调用得没错，但链接时没有实现）。常见原因：

1. 写了函数声明但**忘了写实现**
2. 忘了链接对应的库（如数学库要加 `-lm`）
3. 函数名拼写错误，或 C / C++ 混编时缺 `extern "C"`
4. 多个源文件时，漏把某个 `.o` 或 `.c` 交给编译器

对应地还有：

```text
multiple definition of `xxx'      → 符号被定义了多次（头文件里写了函数体最常见）
```

> 注意区分：`undefined reference` 是**链接期**错误（找不到符号），语法错误是**编译期**错误。前者编译器不会提示行号，初学者容易懵。

## 四、优化

`gcc` 通过 `-O` 控制优化级别：

| 选项 | 含义 |
|---|---|
| `-O0` | 不优化（默认，便于调试） |
| `-O1` / `-O2` / `-O3` | 逐级加强优化 |
| `-Os` | 优化体积 |
| `-Og` | 兼顾调试的优化 |

优化可能做的事：常量折叠、循环展开、内联、死代码消除、寄存器分配。

> 编译优化是性能的重要手段，但**不要用 `-O3` 去掩盖错误的算法复杂度**——先用对算法，再谈优化。

## 📌 易错点

1. **以为 `.o` 就能直接跑**——目标文件地址未定、库函数未合并，必须链接。
2. **`undefined reference` 当成语法错误去改代码**——这是链接期符号缺失，要检查实现、库和 `-l` 选项。
3. **头文件里直接写函数体**——多个 `.c` 同时包含该头文件会导致 `multiple definition`。
4. **忘了 `-o` 后面跟的是输出名**——`gcc -o hello hello.c` 里 `hello` 是产物，不是输入。
5. **调试时用 `-O2` 然后发现断点乱跳**——优化会重排/内联代码，调试请用 `-O0 -g`。
6. **用优化级别掩盖算法问题**——`-O3` 救不了 `O(n²)`。
