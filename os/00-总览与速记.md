## 二、核心口诀速记卡

1. **进程三态**：就绪等 CPU、运行占 CPU、阻塞等事件
2. **状态迁移**：阻塞被唤醒**只能回就绪**，不能直接上 CPU
3. **特权指令**：只在内核态执行（IO 指令、改 PSW）；用户程序进内核的唯一合法入口 = **系统调用**
4. **IPC 二选一**：共享内存**最快但需自己同步、不能跨机器**；消息传递**要拷贝但可跨机器**（→ socket 的起点）
5. **栈帧**：参数 + 返回地址 + 旧基址 + 局部变量；递归太深必爆栈
6. **编译四步**：预处理（`.i`）→ 编译（`.s`）→ 汇编（`.o`）→ 链接（可执行）
7. **链接错误**：`undefined reference` = 链接期找不到实现，不是语法错
8. **线程判态**：只缺 CPU = 就绪，缺别的 = 阻塞；TCB 存现场，切换 = 存 A 恢复 B
9. **线程映射**：多对一不能多核并行，一对一 / 多对多可以
10. **三级调度**：高级造进程、中级换内存、低级给 CPU
11. **调度算法**：FCFS 护航、SJF 饥饿、RR 分时、MLFQ 跑不完就降级；EDF 谁先交卷、LLF 谁最来不及（L = 截止 − 现在 − 剩余）
12. **优先级倒置**：H 等 L 的锁、M 插队抢 L → 继承：L 借 H 的优先级赶紧放锁
13. **死锁四条件**：互斥、请求保持、不可抢占、循环等待——破一即防
14. **死锁应对**：预防破条件、避免查安全（银行家：`Need = Max − Allocation`）、检测允许发生、解除杀进程
15. **死锁三兄弟**：死锁互相等、饥饿轮不上、死循环停不下
